### IMU 必要性论证（四轮麦轮车）

> 用户疑问：整车是四轮（麦轮全向），是否还需要 IMU？结论：**仍需，但可后置。**

1. **麦轮能从四轮编码器解出 vx / vy / ω**——这是全向底盘相对差速车的优势，也是「四轮不需要 IMU」这一看法的来源。差速车受非完整约束（不能侧移），麦轮四轮独立、理论上三轴速度都能解。

2. **但本任务的精度压力集中在「航向 θ」，恰是麦轮轮速解算最不可靠的量。**
   推入方向 = 棋子相对方位 + 车体绝对航向（docs/00 判断一，航向 ±0.5°级）。
   麦轮的 ω 由四轮转速**差分**得出，对以下误差高度敏感：
   - 左右轮有效半径不一致（辊子受压变形、地面软硬差异）；
   - 轮距/轴距几何标定误差；
   - **横移（strafe）时左右辊子滑移不对称 → 产生虚假 ω → 航向漂移**。
   即：最需要精度的「贴墙横移 + 定向推入」工况，恰好是麦轮 ω 估计最不稳的工况。

3. **IMU 陀螺仪直接测角速度**：1kHz 高带宽、不依赖地面接触、不受打滑影响，是编码器航向的互补对：
   - 陀螺仪：短期准（打滑无关），长期零偏漂移；
   - 编码器航向：长期无漂，但打滑时错、带宽低；
   - EKF / 互补滤波融合后做到航向 ±0.5° 是标准做法。

4. **结论与节奏**：四轮麦轮**不构成弃用 IMU 的理由**，至少应保留一路 yaw 陀螺。
   但它不是 W1 前置件——先跑纯编码器 + 里程计，第二轮定位标定时用**实测漂移作闸门**：
   若连续平移/斜移累计导致「3m 横向误差 > 50mm 或航向误差 > 3°」则补购 IMU 融合，否则暂缓。
   这与「动力、视觉验证后再购」的节奏一致。
