## 6. 采购检查清单

采购时逐项确认：

- [ ] 电机是 **12V** 版本（不是 6V/24V）
- [ ] 电机**带霍尔编码器**（不是纯电机）
- [ ] 减速比在 1:50~1:90 之间
- [ ] 驱动模块是 **BTS7960/IBT-2**，不是 TB6612
- [ ] 主控板**不带**无线模块
- [ ] 相机镜头是 **2.8mm**（不是 1.8mm 或 3.6mm）
- [ ] 电池是 **3S**（不是 2S/4S），带平衡头
- [ ] DC-DC 输出电流 **≥3A**
- [ ] 打印耗材是 **PETG**
- [ ] **热熔铜螺母**配套 M3
- [ ] 低压报警器阈值 **10.5V**
- [ ] 激光模组标称 **≤1mW**
