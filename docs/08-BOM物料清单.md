## 3. 缺料清单（原 BOM 有、本次未购）

| 物料 | 影响 | 建议 |
|---|---|---|
| **电机端 104 电容 ×4** | D24A 板上没有电机端 RC，有刷噪声无抑制 | 建议补购 |
| **IMU（ICM20602）** | 无航向基准，航迹推算漂移 | 补购或板载替代 |
| **下视相机** | 下视视觉伺服无法实现 | 补购或改开环直推 |
| BTS7960 驱动 | 现用 TB6612，堵转能力弱 | 视电机实测堵转决定 |
| ST-Link V2 | 已用 PWLINK2 替代 | 无需 |
| 万向球 | 原设计从动支撑 | 麦轮方案不需要 |
| 推板柔性件 / 五金热熔铜螺母 | 结构件 | 待机械重构后补 |
| **激光模组（650nm 1mW）** | C9 强制必须搭载 | 验证后再购（赛题强制） |
| 限流电阻 + 安装座 | 配套激光 | 验证后再购 |
| 低压报警器 / XT60 / 保险丝 | 电源保护 | 建议补购 |

> ⚠️ 激光模组是赛题硬性要求（C9/C16），但按计划**动力系统验证 + 视觉识别验证完成后**再购（触发条件见 [10](10-开发计划与里程碑.md) §0）。

## 7. 原方案对照（历史备份，仅备查）

原五轮迭代方案关键点（详见 16 章历史与其余 docs）：

- 底盘：**差速** + φ65 橡胶轮 + 万向球，带盒式推板（00 判断二否决麦轮）
