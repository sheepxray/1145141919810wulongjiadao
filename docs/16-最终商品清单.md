## 4. 与原五轮迭代的差异（快照）

| 项 | 原方案（16 章历史） | 实际下单 | 说明 |
|---|---|---|---|
| 底盘 | 差速 + φ65 橡胶轮 | 麦轮 60mm ×4 | 00 判断二曾否决麦轮 |
| 驱动 | BTS7960/IBT-2 | TB6612 | 曾明确「不要买」 |
| 主控 | STM32H723 | STM32G474VET6 | RAM 大幅下降 |
| 视觉 | RK3588 | K230D 128M | 算力下沉 |
| 相机 | IMX219 ×2 + 备用 | OV5640 ×1 | 帧率/数量双降 |
| 电池 | 3S 1500mAh LiPo | 3S 2600mAh 锂电组 | 容量更大、更安全 ✅ |
| 下载器 | ST-Link V2 | PWLINK2 | 兼容替代 ✅ |
