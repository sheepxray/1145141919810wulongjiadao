### 每一轮的核心结论

| 轮次 | 主题 | 核心发现 |
|---|---|---|
| **1** | 电源与电流 | 真正的风险是**电机烧毁**（堵转 86 秒），解法是**限流**不是换电池 |
| **2** | 主控与算力 | 瓶颈在**视觉平台的 CPU**（非 NPU）；G431 控制环只占 2% |
| **3** | 1080p 视觉 | 关键是**降采样用 RGA 硬件**（CPU 降采样会让帧率掉到 28） |
| **4** | 字符识别 | 识别输出**概率分布**，优先级必须用**期望值**而非 argmax |
| **5** | 建模与 BOM | 相机立柱使总高从 99.5 → **160mm**（原模型漏算） |

## 7. 采购检查清单

### 动力与驱动

- [ ] 电机是 **12V** 版本（不是 6V/24V）
- [ ] 电机**带霍尔编码器**
- [ ] 减速比在 **1:50 ~ 1:90**（推荐 1:56）
- [ ] 驱动模块是 **BTS7960/IBT-2**（不是 TB6612）
- [ ] **INA240 模块 ×2**（限流必需，别漏买）

### 控制与视觉

- [ ] 主控是 **STM32H723**（不是 G431/F103）
- [ ] 视觉平台是 **RK3588**（不是 K230）
- [ ] 相机是 **IMX219**（不是 OV5640）
- [ ] 主控板与视觉板**都不带**无线模块
- [ ] CSI 排线长度够（相机到板子的实际走线距离）
- [ ] 散热片与风扇配套

### 电源

- [ ] 电池是 **3S**（不是 2S/4S），带平衡头
- [ ] 5V buck 输出 **≥5A**
- [ ] 保险丝是 **5A 慢熔**（不是 10A 快熔）
- [ ] 低压报警器阈值 **10.5V**
- [ ] 电解电容 **≥1000µF 低 ESR**（视觉轨）

### 结构

- [ ] 打印耗材是 **PETG**（不是 PLA）
- [ ] **M3 热熔铜螺母**配套
- [ ] 压簧 k≈0.5 N/mm，2 个
- [ ] PTFE 胶带 0.5mm

### 合规

- [ ] 激光模组标称 **≤1mW**
- [ ] 限流电阻配套
- [ ] **全套无任何无线模块**

## 8. 下单后的第一批验证（M1 阶段）

采购到货后，按优先级验证：

| 优先级 | 验证项 | 方法 | 通过标准 |
|---|---|---|---|
| 🔴 | **RK3588 能否 1080p@30** | 跑 profiler | ≥ 30 FPS |
| 🔴 | **RGA 驱动可用性** | 测 `librga` 缩放 | 单次 < 3ms |

| 🔴 | **推板三个测试** | 打印样件实测 | 见 docs/02 §3.5 |
| 🟡 | 5V 轨压降 | 示波器观测堵转 | 跌落 < 0.3V |
| 🟡 | IMX219 实际帧率 | K230/RK3588 实测 | ≥ 30 FPS 稳定 |
| 🟢 | 整机称重 | 厨房秤 | 回填 mass_budget |

> **前三项任一失败都会影响方案** —— 必须在 M1 阶段（第 1–4 周）闭环。
