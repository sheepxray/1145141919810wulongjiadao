# 03 · 电控与驱动系统

---

## 1. 主控：STM32G431

### 1.1 为什么是 G431

| 特性 | 对本任务的意义 |
|---|---|
| **硬件 FPU**（Cortex-M4F） | 双环 PID + 航迹推算全用浮点，不必改写定点，开发快、不易出错 |
| 高级定时器 ×2 | 2 路互补 PWM（20kHz），带死区（虽然本方案用有刷电机，留升级空间） |
| 通用定时器 ×4+ | 2 路编码器正交解码 + 1 路系统时基 |
| 12-bit ADC ×2 | 电池电压监测，无需外部分压芯片 |
| 成本约 ¥45（核心板） | 在 ¥2000 预算下毫无压力 |

> F103C8T6 也能胜任，但**无 FPU**，浮点靠软件模拟，在 1kHz 双环 PID 下会成为瓶颈。
> 预算有 ¥1193 余量，没有理由省这 ¥20。

### 1.2 引脚分配

| 功能 | 引脚 | 外设 | 说明 |
|---|---|---|---|
| 左电机 PWM | PA8 | TIM1_CH1 | 20kHz |
| 左电机 DIR | PB0 | GPIO | 方向 |
| 右电机 PWM | PA9 | TIM1_CH2 | 同左 |
| 右电机 DIR | PB1 | GPIO | |
| BTS7960 使能 | PB2 | GPIO | EN，低功耗/急停 |
| 左编码器 A/B | PA0 / PA1 | TIM2_CH1/CH2 | 正交解码 |
| 右编码器 A/B | PA6 / PA7 | TIM3_CH1/CH2 | 正交解码 |
| IMU SPI | PA5/PA6/PA7 | SPI1 | ⚠️ **与编码器冲突，见 1.3** |
| K230 UART | PA2/PA3 | USART2 | 921600 |
| 调试 UART | PA14/PA15 | USART1 | 仅有线，**禁止无线** |
| 拨码开关 | PB12-15 | GPIO | 队伍编号/球门侧配置 |
| 自检 LED | PC13 | GPIO | 状态指示 |
| 蜂鸣器 | PB5 | GPIO | 故障报警 |
| 电池电压 | PA4 | ADC1_IN4 | 分压监测 |

### 1.3 ⚠️ 引脚冲突必须修正

上表中 SPI1（PA5/PA6/PA7）与编码器 TIM3（PA6/PA7）**冲突**。必须二选一改到别处。

**修正方案**：IMU 改用 **SPI2**：

| 功能 | 改为 | 外设 |
|---|---|---|
| IMU SPI | PB13/PB14/PB15 + PB12(CS) | SPI2 |
| 拨码开关 | 移到 PB6-PB9 | GPIO（从 USART1 的备用引脚区取） |

> 这类冲突在纸上很难看出来，**画完原理图必须用 STM32CubeMX 的引脚检查跑一遍**，
> 它会直接标红冲突。

## 2. 电机与驱动

### 2.1 电机选型：JGB37-520 12V

| 参数 | 取值 |
|---|---|
| 类型 | 有刷直流减速电机，520 级 |
| 电压 | 12V |
| 空载转速 | 约 180–350 rpm（视减速比） |
| 减速比 | 建议 **1:50 ~ 1:90**（对应轮速 0.5–1.0 m/s @ φ65 轮） |
| 编码器 | 霍尔，11 线 × 减速比（典型 500 线/转输出） |
| 堵转电流 | **2–5 A** ← 这是决定驱动板的关键参数 |

**选减速比的依据**：车速按 0.8 m/s 设计。

```
轮周长 = π × 0.065 = 0.204 m
所需转速 = 0.8 / 0.204 × 60 = 235 rpm
考虑电压跌落与负载，空载转速取 300–350 rpm
```

### 2.2 驱动：BTS7960 (IBT-2) ×2

| 参数 | BTS7960 | TB6612（已否决） |
|---|---|---|
| 连续电流 | **43 A** | 1.2 A |
| 峰值 | 60 A | 3.2 A（极短） |
| VM 范围 | 5.5–27 V | 2.5–13.5 V |
| 3S 满电 12.6V | ✅ 充裕 | ⚠️ 加感性尖峰逼近绝对最大 15V |
| 单件价格 | 约 ¥12 | 约 ¥8 |

#### 为什么必须换掉 TB6612

**这是本方案中唯一一个会直接导致"失控"的硬件错误。**

1. JGB37-520 堵转电流 **2–5 A/台**，TB6612 只能连续 1.2 A/通道；
2. 本车 1.5kg 且有推板，**顶墙、顶棋子、顶对方车时必然堵转**；
3. 双电机同时堵转 → 4–10 A 灌进两片 TB6612 → **热保护跳闸**；
4. 跳闸 = 驱动失效 = **丢控制权**，车会按惯性冲向未知方向。

这比"烧板子"更危险 —— 烧板至少是静止失效，热保护跳闸是**运动中的失控**，
可能撞到对方车或被判"恶意冲撞"。

> 备选：DRV8871（3.6A、6.5–45V）单路模块 ×2，性能有余量。
> **DRV8833 不可用**（VM 上限约 10.8V，3S 超压）。

### 2.3 接线

```
   3S LiPo (+) ──┬── 保险丝 10A ──┬── BTS7960(L) B+ ── 左电机
                 │                 └── BTS7960(R) B+ ── 右电机
                 │
                 └── DC-DC 5V ─── K230 / 相机
                       │
                       └── DC-DC 3.3V ── STM32 / IMU

   所有 GND 单点汇流到电池负极（星型接地，见 docs/06）
```

**BTS7960 每路需要 4 个控制信号**：R_EN、L_EN、R_PWM、L_PWM。
简化接法（单向驱动 + 方向引脚）：

| BTS7960 引脚 | 接到 | 说明 |
|---|---|---|
| R_EN | 3.3V（或 PA_EN 统一使能） | 常使能 |
| L_EN | 3.3V | 常使能 |
| R_PWM | STM32 PWM | 正转占空比 |
| L_PWM | STM32 PWM | 反转占空比 |

**注意**：BTS7960 模块的两个 PWM 引脚**不能同时给高**（直通）。
本方案用"一个给 PWM、另一个给 0"的方式驱动，天然避免直通。
软件里加一层互锁保护（`set_pwm(dir, duty)` 统一设置两个通道）。

## 3. 控制环

### 3.1 双环结构

```
    目标 (v_cmd, ω_cmd)
            │
    ┌───────┴────────┐
    │   运动学分解     │  差速模型
    │ v_L = v − ω·B/2 │  B = 轮距 150mm
    │ v_R = v + ω·B/2 │
    └───────┬────────┘
            │
    ┌───────┴────────┐
    │  速度环 PID     │  1 kHz
    │  (每轮独立)      │  反馈 = 编码器
    └───────┬────────┘
            │
          PWM 20kHz
```

**外层航向环**（500 Hz）：

```
    目标航向 θ_cmd  ──→ [+] ──→ PID ──→ ω_cmd
                        −│
                    IMU 航向 θ
```

### 3.2 参数起点

| 环 | 频率 | Kp | Ki | Kd | 说明 |
|---|---|---|---|---|---|
| 速度环 | 1 kHz | 0.8 | 0.35 | 0 | 输出为 PWM 占空比 |
| 航向环 | 500 Hz | 2.5 | 0 | 0.15 | 输出为 ω_cmd |

> 这些只是**起点**，必须实测整定。整定顺序：先速度环（让轮速跟随阶跃指令无超调），
> 再航向环（让原地转向无振荡）。

### 3.3 必须用编码器闭环，不能用开环 PWM

3S 电池从满电 12.6V 放到 9.0V，同一 PWM 下**轮速变化约 30%**。
开环 PWM 会让里程计和推程全部不准。**速度环是里程计可信的前提。**

## 4. IMU：ICM20602

### 4.1 为什么不用 MPU6050

| 指标 | ICM20602 | MPU6050 |
|---|---|---|
| 陀螺零偏稳定性 | 好 | 差 |
| 最高 ODR | 32 kHz | 8 kHz |
| 内置 DMP | 有 | 有 |
| 价格 | 约 ¥25 | 约 ¥10 |
| 市场风险 | 低 | **廉价模块大量是 MPU6500 贴牌** |

航向积分对零偏稳定性极敏感：零偏 0.1°/s 时，60 秒累积漂移 **6°**。
选 ICM20602 是因为**它是定位链路的精度瓶颈所在**。

### 4.2 配置

| 项目 | 取值 | 理由 |
|---|---|---|
| 陀螺量程 | ±500 °/s | 车原地转向最大角速度约 300°/s |
| 陀螺 ODR | 1 kHz | 与速度环同步 |
| 加速度量程 | ±4 g | 撞击时峰值 |
| 低通滤波 | 约 100 Hz | 滤电机振动 |
| 接口 | SPI2，10 MHz | 比 I²C 快且不受总线锁死影响 |

### 4.3 航向估计

**只用陀螺积分**，不用磁力计（室内电机磁场干扰大）。
零偏在**静止时自动标定**（上电后 1 秒静置，取均值），并可由"撞墙重定位"周期性清零。

## 5. 堵转检测与保护

由于 TB6612 的教训，**必须显式实现堵转保护**：

```c
// 伪代码
if (abs(target_speed) > 50 && abs(actual_speed) < 10) {
    stall_counter++;
    if (stall_counter > 200) {        // 200ms @ 1kHz
        motor_stop();
        report_error(ERR_STALL);
    }
} else {
    stall_counter = 0;
}
```

**注意区分"正常堵转"与"故障堵转"**：
推棋子时推板顶着墙，电机本来就该是堵转状态。所以保护不能简单停机，
而应：**堵转时把电流限制在安全范围，并让决策层知道"我顶住了"**。

```
堵转 → 降 PWM 到维持值（约 30%）→ 通知决策层"已到位"或"受阻"
```

这才是正确语义：堵转是**任务信息**，不只是故障。

## 6. 上电自检

C8 要求全程自主、禁止人工干预。因此**上电即自启**，自检必须自动完成：

| 步骤 | 检查内容 | 失败处理 |
|---|---|---|
| 1 | IMU 通信 + 静止零偏标定 | 蜂鸣器 3 短响，LED 快闪 |
| 2 | 编码器：轻微转动电机，两轮都应有计数 | 报警 |
| 3 | K230 串口握手（见 docs/11） | 重试 3 次，失败则进入**降级策略 B** |
| 4 | 电池电压 ≥ 10.5V | 低压则报警（但继续，因为可能只是没充满） |
| 5 | 激光模组点亮 | 仅记录，不阻塞 |

**第 3 步失败不应导致整车不动** —— 必须能进降级策略（见 [docs/07](07-软件架构与决策策略.md)）。

## 7. 禁止事项（合规）

| 禁止 | 检查 |
|---|---|
| 任何无线模块 | **调试口用有线串口**，PCB/模块上不得有蓝牙/WiFi 芯片 |
| 电磁铁 | 不得有 |
| 激光功率超标 | 串限流电阻，实测 ≤0.7mW（留 30% 余量） |
| 破坏性装置 | 不得有 |

**采购检查清单**：买电机驱动、主控板时注意别买带 ESP8266/蓝牙的"智能小车套件"，
那些模块会构成"遥控能力"，即使不用也可能被判违规。
