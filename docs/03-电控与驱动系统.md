## 1. 主控：STM32G474VET6

### 1.1 为什么是 G474

| 特性 | 对本任务的意义 |
|---|---|
| **硬件 FPU**（Cortex-M4F） | 四轮麦轮运动学 + 双环 PID + 航迹推算全用浮点 |
| 高级定时器（带死区） | 4 路 PWM（10 kHz）——本方案用有刷电机，死区留升级空间 |
| 通用/32 位定时器 | **4 路编码器正交解码** + 系统时基 |
| 12-bit ADC ×多通道 | 电池电压监测（可用驱动板板载 1/11 分压） |
| 170 MHz / 低分辨率损失 | 四路 9 kHz 编码器计数的余量很大 |

> ⚠️ **引脚资源核对**：4 路电机 = **4 PWM + 8 IO + 1 STBY**（共 13 脚），
> 4 路编码器 = **8 脚**，另有 IMU SPI（5）、K230 UART（2）、调试 UART（2）、
> 拨码（4）、LED/蜂鸣器（2）、ADC（1）。
> **本文件早期版本只规划了 2 路电机** —— 上表是旧差速方案遗留，
> 必须在 CubeMX 里按 4 路重新分配（见 §1.3）。

### 1.2 引脚分配（⚠️ 4 路版本，需在 CubeMX 复核）

| 功能 | 引脚 | 外设 | 说明 |
|---|---|---|---|
| 电机 A PWM | PA8 | TIM1_CH1 | 10 kHz |
| 电机 B PWM | PA9 | TIM1_CH2 | 10 kHz |
| 电机 C PWM | PA10 | TIM1_CH3 | 10 kHz |
| 电机 D PWM | PA11 | TIM1_CH4 | 10 kHz |
| A 方向 | PB0 / PB1 | GPIO | AIN1 / AIN2 |
| B 方向 | PC4 / PC5 | GPIO | BIN1 / BIN2 |
| C 方向 | PB10 / PB11 | GPIO | CIN1 / CIN2 |
| D 方向 | PD2 / PC12 | GPIO | DIN1 / DIN2 |
| **STBY 使能** | PC6 | GPIO | ★ 软急停，高电平使能 |
| 编码器 A | PA0 / PA1 | TIM2_CH1/CH2 | 正交解码 |
| 编码器 B | PA6 / PA7 | TIM3_CH1/CH2 | 正交解码 |
| 编码器 C | PB6 / PB7 | TIM4_CH1/CH2 | 正交解码 |
| 编码器 D | PD12 / PD13 | TIM4 备用/GPIO 中断 | 若 TIM 不够用走 GPIO 双沿中断 |
| IMU SPI2 | PB13/PB14/PB15 + PB12(CS) | SPI2 | ⚠️ 见 1.3 |
| K230 UART | PA2/PA3 | USART2 | 921600 |
| 调试 UART | PA14/PA15 | USART1 | 仅有线，**禁止无线** |
| 拨码开关 | PB3-PB5 + PC7 | GPIO | 队伍编号/球门侧配置 |
| 自检 LED | PC13 | GPIO | 状态指示 |
| 蜂鸣器 | PB8 | GPIO | 故障报警 |
| 电池电压 | PA4 | ADC1_IN4 | 驱动板 ADC 引脚输出（已 1/11 分压） |

> ⚠️ **上表是为了满足 4 路电机 + 4 路编码器的最小改动版本，
> 尚未经过 CubeMX 校验** —— 尤其是 `PA10/PA11`（TIM1_CH3/4）、
> `PD12/PD13`（TIM4 已被编码器 C 占用）两处最容易出错。
> **画完原理图必须用 STM32CubeMX 的引脚检查跑一遍。**

### 1.3 ⚠️ 引脚冲突教训（保留）

早期版本把 IMU 放在 SPI1（PA5/PA6/PA7），与编码器 TIM3（PA6/PA7）**冲突**。

**修正**：IMU 改用 **SPI2**（PB13/PB14/PB15 + PB12 CS 控制片选）。

> 这类冲突在纸上很难看出来，**画完原理图必须用 STM32CubeMX 的引脚检查跑一遍**，
> 它会直接标红冲突。**4 路电机 + 4 路编码器会显著加剧这类冲突，务必先做引脚规划。**

## 2. 电机与驱动

### 2.1 电机：MG513X 12V （麦轮全向，4 台）

| 参数 | 取值 |
|---|---|
| 型号 | **MG513X** 有刷直流减速电机 |
| 额定电压 | **12 V** |
| 减速比 | **1:28** |
| 空载转速 | **370 ± 12 rpm** |
| 额定转速 | **300 ± 12 rpm** |
| 额定电流 / 堵转电流 | **0.36 A / 3.2 A**（⚠️ 堵转值待实测，见 docs/17 §3） |
| 额定转矩 / 堵转转矩 | **1 / 4.5 kgf·cm** |
| 编码器 | 霍尔，13 线/相 → **364 P/r 单相、1456 count/r 四倍频** |
| 单台重量 | **0.17 kg**（4 台 = **0.68 kg**） |

**车速核算**（φ60 麦轮，轮周长 0.1885 m）：

| 状态 | 转速 | 车速 |
|---|---|---|
| 空载 | 370 rpm | 1.16 m/s |
| 额定 | 300 rpm | **0.94 m/s** |

> 比 0.8 m/s 目标快 18%，**用 PWM 限速**，属于速度余量。

### 2.2 驱动：TB6612 四路带稳压板（D24A）

| 参数 | D24A（本次采购） | 说明 |
|---|---|---|
| 芯片 | **2 × TB6612FNG** | 每片 2 路，共 4 路 |
| 单路持续电流 | **1.2 A** | 芯片手册 IOUT(ave) |
| 单路峰值电流 | **3.2 A** | 芯片手册 IOUT(peak)，**不可持续** |
| VM 范围 | **2.5 – 13.5 V**（绝对最大 15 V） | 3S 满电 12.6 V，余量仅 0.9 V |
| 控制方式 | **1 路 PWM + 2 路 IO / 电机** | 共 4 PWM + 8 IO |
| PWM 频率 | **10 kHz**（手册推荐，范围 0–100 kHz） | |
| 使能 | **STBY**，必须拉高 | 推荐由 GPIO 控制以便软急停 |
| 板载稳压 | 5V = RT8279（5 A/500 kHz），3.3V = RT9013 LDO（500 mA） | |
| 过温保护 | **整板 65 °C 切断 5V/3.3V** | ⚠️ **会连坐主控与视觉，见 §2.4** |

### 2.3 接线

```
   3S LiPo (+) ──[主保险丝 ≥15A，待实测]──┬── D24A  Vin+  ── 4× MG513X
                                          │      │
                                          │      ├─ 板载 RT8279 → 5V  → 5V 对外
                                          │      │                    └→ RT9013 → 3.3V 对外
                                          │      │
                                          │      └─ 板载 1/11 分压 → ADC 引脚（电池监测）
                                          │
                                          └── 🔴 独立 DC-DC 5V ≥3A ── K230D + 相机
                                                 （★ 不从驱动板取，见 §2.4）

   所有 GND 单点汇流到电池负极（星型接地，见 docs/06）
```

**每路电机的控制信号**（真值表见规格文档 §2.2）：

| 路 | PWM | IN1 | IN2 | 编码器 |
|---|---|---|---|---|
| A | PWMA | AIN1 | AIN2 | E1A / E1B |
| B | PWMB | BIN1 | BIN2 | E2A / E2B |
| C | PWMC | CIN1 | CIN2 | E3A / E3B |
| D | PWMD | DIN1 | DIN2 | E4A / E4B |

> **与 BTS7960 的关键区别**：TB6612 **每个电机只需 1 路 PWM**（BTS7960 需要 2 路反向 PWM）。
> 不会直通，但 **PWM=0 时是滑行（coast）而非刹车**，
> 需要快速停车时用 **IN1=IN2=1 + PWM=1（制动）**。

### 2.4 🔴 过温保护连坐 —— 本方案最严重的硬件风险

> **D24A 的板级 65 °C 过温保护切断的是 5V / 3.3V 轨，
> 而 STM32 与 K230D 正接在这两轨上。**

```
四路电机长时间堵转（顶墙推棋子）
  → 驱动板升温 → 整板 > 65 °C
  → 保护切断 5V + 3.3V
  → K230D 掉电重启 + STM32 复位
  → 推入动作丢失、里程计/航向清零 → 场上失控
```

**处置（必须做）**：

1. **K230D + 相机走独立 DC-DC 5V ≥3A**，不从驱动板 5V 取电。
2. **STM32 逻辑供电也尽量独立**（或接受「复位后靠状态机快速恢复」）。
3. **堵转降 PWM 保护**（§5）压住发热，不让整板到 65 °C。
4. 实测板级保护行为：是否真的切断、切断后多久恢复。

## 3. 控制环

### 3.1 双环结构

```
    目标 (v_cmd, ω_cmd)
            │
    ┌───────┴────────┐
    │   运动学分解     │  差速模型
    │ v_L = v − ω·B/2 │  B = 轮距 150mm
    │ v_R = v + ω·B/2 │
    └───────┬────────┘
            │
    ┌───────┴────────┐
    │  速度环 PID     │  1 kHz
    │  (每轮独立)      │  反馈 = 编码器
    └───────┬────────┘
            │
          PWM 20kHz
```

**外层航向环**（500 Hz）：

```
    目标航向 θ_cmd  ──→ [+] ──→ PID ──→ ω_cmd
                        −│
                    IMU 航向 θ
```

### 3.2 参数起点

| 环 | 频率 | Kp | Ki | Kd | 说明 |
|---|---|---|---|---|---|
| 速度环 | 1 kHz | 0.8 | 0.35 | 0 | 输出为 PWM 占空比 |
| 航向环 | 500 Hz | 2.5 | 0 | 0.15 | 输出为 ω_cmd |

> 这些只是**起点**，必须实测整定。整定顺序：先速度环（让轮速跟随阶跃指令无超调），
> 再航向环（让原地转向无振荡）。

### 3.3 必须用编码器闭环，不能用开环 PWM

3S 电池从满电 12.6V 放到 9.0V，同一 PWM 下**轮速变化约 30%**。
开环 PWM 会让里程计和推程全部不准。**速度环是里程计可信的前提。**

## 4. IMU：ICM20602

### 4.1 为什么不用 MPU6050

| 指标 | ICM20602 | MPU6050 |
|---|---|---|
| 陀螺零偏稳定性 | 好 | 差 |
| 最高 ODR | 32 kHz | 8 kHz |
| 内置 DMP | 有 | 有 |
| 价格 | 约 ¥25 | 约 ¥10 |
| 市场风险 | 低 | **廉价模块大量是 MPU6500 贴牌** |

航向积分对零偏稳定性极敏感：零偏 0.1°/s 时，60 秒累积漂移 **6°**。
选 ICM20602 是因为**它是定位链路的精度瓶颈所在**。

### 4.2 配置

| 项目 | 取值 | 理由 |
|---|---|---|
| 陀螺量程 | ±500 °/s | 车原地转向最大角速度约 300°/s |
| 陀螺 ODR | 1 kHz | 与速度环同步 |
| 加速度量程 | ±4 g | 撞击时峰值 |
| 低通滤波 | 约 100 Hz | 滤电机振动 |
| 接口 | SPI2，10 MHz | 比 I²C 快且不受总线锁死影响 |

### 4.2.1 接线（ICM-20602 → STM32G474VET6，SPI2）

| 模块引脚 | 接 STM32 | 外设/功能 | 说明 |
|---|---|---|---|
| VCC | 3V3 | 电源 | 与主控同一电源域 |
| GND | GND | 地 | **必须与主控共地** |
| SCL | PB13 | SPI2_SCK | 时钟 |
| SDA | PB15 | SPI2_MOSI | 主→从数据 |
| SDO / SA0 | PB14 | SPI2_MISO | 从→主数据 |
| CS | PB12 | GPIO_Output | 软件片选（拉低=选中） |
| INT | 空闲 EXTI GPIO（如 PB10） | EXTI | data-ready，上升沿触发 |
| AD0 | GND | — | SPI 模式下是寄存器地址 LSB，接地 |

**SPI 要点（易错）**：
- **CS 决定接口模式，不能悬空**：上电时 CS 拉高 = I²C 模式；拉低 = SPI。务必接 MCU 控制。
- 时序：**≤10 MHz**，**Mode 0 或 Mode 3**（均支持，常用 Mode 3）、MSB first、8-bit。
- 首字节协议：MSB = R/W（1 读 0 写）+ 低 7 位寄存器地址；读数据时 MISO 回数据。
- 电源：VCC 就近并 0.1µF + 10µF 去耦。
- 安装：**水平安装、Z 轴朝上**，放车体几何中心/中线上，远离电机与电机线。

### 4.3 航向估计

**只用陀螺积分**，不用磁力计（室内电机磁场干扰大）。
零偏在**静止时自动标定**（上电后 1 秒静置，取均值），并可由"撞墙重定位"周期性清零。

## 5. 堵转检测与保护

> **为什么必须做**：MG513X 堵转电流 **≥1.4 A**（保守读数 3.2 A），
> 超过 TB6612 单路持续 **1.2 A**；四路同时堵转会把板子加热到 65 °C 触发保护，
> 进而**切断 5V/3.3V 把主控和视觉一起断电**（§2.4）。

**注意区分"正常堵转"与"故障堵转"**：
推棋子时推板顶着墙，电机本来就该是堵转状态。所以保护**不能简单停机**，
而应：**堵转时把输出降到维持值，并让决策层知道"我顶住了"**。

```c
/* 速度环内，1 kHz 调用 */
if (fabs(target_rpm) > 50.0f && fabs(actual_rpm) < 10.0f) {
    if (++stall_cnt > 200) {            /* 200 ms @ 1 kHz */
        /* ★ 不是停机，而是把 PWM 压到维持值 */
        motor_set_duty(m, DUTY_HOLD);   /* ≈30% */
        report_event(EV_STALL_HOLD);    /* 决策层：已到位/受阻 */
    }
} else {
    stall_cnt = 0;
    if (stall_hold) {                   /* 脱离堵转后恢复闭环 */
        stall_hold = false;
        report_event(EV_STALL_RELEASED);
    }
}
```

| 参数 | 取值 | 理由 |
|---|---|---|
| 判据窗口 | 200 ms | 短于动作节拍，长于启动冲击 |
| 维持占空比 | ≈30% | 顶墙所需的最小保持力 |
| 脱离恢复 | 立即恢复闭环 | 需要能继续推进下一枚 |

**这才是正确语义：堵转是任务信息，不只是故障。**

**二级保护（推荐）**：加 INA240 或使用板载 VM 采样，
把单路电流限到 **1.2 A**；这是唯一能把「长时间顶墙」变安全的办法。

## 6. 上电自检

C8 要求全程自主、禁止人工干预。因此**上电即自启**，自检必须自动完成：

| 步骤 | 检查内容 | 失败处理 |
|---|---|---|
| 1 | IMU 通信 + 静止零偏标定 | 蜂鸣器 3 短响，LED 快闪 |
| 2 | 编码器：轻微转动电机，**4 路都应有计数** | 报警并标出失效路 |
| 3 | K230 串口握手（见 docs/11） | 重试 3 次，失败则进入**降级策略 B** |
| 4 | 电池电压 ≥ 10.5V | 低压则报警（但继续，因为可能只是没充满） |
| 5 | 激光模组点亮 | 仅记录，不阻塞 |

**第 3 步失败不应导致整车不动** —— 必须能进降级策略（见 [docs/07](07-软件架构与决策策略.md)）。

## 7. 禁止事项（合规）

| 禁止 | 检查 |
|---|---|
| 任何无线模块 | **调试口用有线串口**，PCB/模块上不得有蓝牙/WiFi 芯片 |
| 电磁铁 | 不得有 |
| 激光功率超标 | 串限流电阻，实测 ≤0.7mW（留 30% 余量） |
| 破坏性装置 | 不得有 |

**采购检查清单**：买电机驱动、主控板时注意别买带 ESP8266/蓝牙的"智能小车套件"，
那些模块会构成"遥控能力"，即使不用也可能被判违规。
