# 01 · 总体方案

> ⚠️ **方案裁决（2026-09-28）**：仓库已按实际采购定为 **麦轮全向 + K230D + 单 OV5640 + STM32G474 + TB6612**（见 [08 BOM](08-BOM物料清单.md)、[16 商品清单](16-最终商品清单.md)、[10 计划](10-开发计划与里程碑.md)）。本文为早期/旧平台版本，其中与当前采购冲突的选型与指标以 16/17 为准；架构思路与算法结论多数继续沿用。

## 1. 系统架构

```
┌──────────────────────── K230 视觉协处理器 ────────────────────────┐
│                                                                    │
│   前视相机 (俯角15°)              下视相机 (俯角60°)                │
│     · 棋子搜索：颜色阈值 + 轮廓      · 停车读字：小 CNN 分类         │
│     · 近场测墙：挡板上下边缘          · 推入段伺服：保持棋子居中      │
│     · 对手车/障碍：大色块检测         · 落位确认：棋子是否进区        │
│                                                                    │
│              输出：结构化的目标列表 + 相对方位 + 类别               │
└──────────────────────────────┬─────────────────────────────────────┘
                               │ UART 921600, ~10Hz
                               │ 帧格式见 docs/11
┌──────────────────────────────┴─────────────────────────────────────┐
│                    STM32G431 运动主控                               │
│                                                                     │
│   · 2 路编码器正交解码 (TIM)        · 2 路 PWM 20kHz (TIM)          │
│   · ICM20602 (SPI) 航向积分          · 双环 PID: 速度环 + 航向环     │
│   · 航迹推算 EKF                     · 状态机 (docs/07)              │
│   · 堵转检测与保护                   · 上电自检                      │
└──────┬──────────────────────────────────────────────┬──────────────┘
       │                                              │
  BTS7960 ×2                                     电源系统
       │                                              │
  JGB37-520 ×2 (差速)                       3S LiPo → 12V / 5V / 3.3V
```

## 2. 为什么这样切分

| 决策 | 理由 |
|---|---|
| 视觉与运动分离 | CNN 推理需 NPU（STM32 跑不动）；1kHz 硬实时需 MCU（Linux 给不了） |
| 耦合只有一个串口 | 接口面最小 = 调试最容易。10Hz 的"目标列表"足够低频，不必上高速总线 |
| K230 不做电机控制 | CanMV 的 RT-Smart + Linux 混合调度不具备 1kHz 确定性 |
| 相机分成两个 | 见 [docs/02](02-机械系统设计.md) 第 5 节：垂直下视的可见区间只有 0–76mm，覆盖不到推板前方；而看远墙与近场读字的几何需求方向相反 |

## 3. 数据流

```
[前视帧] → 颜色阈值分割 → 连通域 → 棋子候选 (图像坐标 + 颜色)
                                    ↓
                          [车体坐标变换] → 候选列表
                                    ↓
                          [目标打分函数] (docs/07)
                                    ↓
                          选中目标 → 生成接近路径
                                    ↓
[停车] → [下视帧] → 小 CNN → 分值 + 是否帅/将  → 更新该棋子类别
                                    ↓
                          两段式接近 → 第二段下视伺服 → 推入
                                    ↓
                          [撞墙重定位] → 位姿清零 → 下一个目标
```

## 4. 方案选型对比

### 4.1 底盘

| 方案 | 优点 | 缺点 | 结论 |
|---|---|---|---|
| **差速 + 侧裙推板** | 2 电机；成本/质量/故障点减半；3D 打印易实现 | 微调方向需转向 | ✅ **采用** |
| 麦克纳姆轮全向 | 可平移；对准与推入解耦 | 4 电机；3D 打印辊子质量差；受推力时侧向漂移污染推入段；**不改变车宽，解决不了贴墙问题** | ❌ |
| 履带 | 抓地好 | 转向滑移大、里程计差；3D 打印履带易断 | ❌ |

**决定性理由**：反对差速的核心理由是"转向时推板会把棋子甩出"，但**侧裙从机构上消掉了这个理由**，
而麦轮解决不了真正的问题（车宽）。详见证推导见 [docs/02](02-机械系统设计.md) 第 3.2 节。

### 4.2 定位

| 方案 | 精度 | 成本 | 结论 |
|---|---|---|---|
| **航迹推算 + 撞墙重定位 + 近场测墙** | 全局 ±50mm 够用 | ¥0（用已有传感器） | ✅ **采用** |
| 全场挡板四边形 PnP | 远场 ±154mm | ¥0 | ❌ 精度不可用 + 退化严重 |
| 激光雷达 | 高 | ¥300+ | ❌ 规则是否允许存疑（见 docs/09 Q2） |
| 激光三角测距 | 取决于标定 | ¥12 | ❌ 明亮场馆 3m 处不可见；滤光片会废掉视觉通道 |
| 视觉里程计（下视光流） | 中 | ¥0 | ⚠️ 可选增强，M3 之后再说 |

**关键认知**：全局定位只需 ±50mm（只要知道球门方向、附近有无棋子），
真正要求精度的是**航向**（IMU，±0.5°）和**棋子相对车体的方位**（下视相机，±3mm）。
**"棋子的绝对坐标"从来没有出现在推入公式里。**

### 4.3 视觉

| 方案 | 结论 |
|---|---|
| **经典 CV 找棋子 + 小 CNN 读字** | ✅ **采用** —— 把 nncase 调试面压到最小 |
| 端到端 YOLO 检测棋子类别 | ❌ 3 个月内数据集与量化风险高 |
| 只做颜色分类不读字 | ⚠️ **降级策略 B**，作为兜底保留 |

**关键认知：颜色是免费的高价值先验。** 中国象棋红方字红、黑方字黑、底色相同，
所以"红/黑"是**颜色阈值**，不需要停车、不需要 CNN。只需推己方颜色的棋子
→ **需要读字的候选立刻减半（16 枚）**。

### 4.4 主控

| 方案 | 结论 |
|---|---|
| **STM32G431** | ✅ 有硬件 FPU，浮点 PID/EKF 不用软浮点；定时器资源充足 |
| STM32F103C8T6 | ⚠️ 可行但无 FPU，浮点运算靠软件；预算有富余故升级 |
| K230 兼任 | ❌ 无 1kHz 确定性 |
| 自研 PCB | ❌ **3 个月来不及打样调试** —— 全部用成品模块 |

### 4.5 驱动

| 模块 | 连续电流 | VM 上限 | 结论 |
|---|---|---|---|
| **BTS7960 / IBT-2** | **43A** | 27V | ✅ **采用** |
| TB6612FNG | 1.2A | 13.5V | ❌ 520 电机堵转 2–5A，必然热保护跳闸 |
| DRV8833 | 1.2A | 10.8V | ❌ 3S 超压 |
| DRV8871 | 3.6A | 45V | ⚠️ 可用备选 |

**TB6612 为什么不行**：本车 1.5kg 且有推板，**顶墙、顶棋子、顶对方车时必然堵转**。
双电机同时堵转 4–10A 灌进两片 TB6612 → 热保护跳闸 → **丢控制权**
（比烧板更危险，会失控冲向未知方向）。

## 5. 设计余量

| 项目 | 设计值 | 上限 | 余量 |
|---|---|---|---|
| 质量 | 987 g | 1500 g | 513 g |
| 成本 | ¥807 | ¥2000 | ¥1193 |
| 长 | 225 mm | 250 mm | 25 mm |
| 宽 | 190 mm | 200 mm | 10 mm |
| 高 | 170 mm | 180 mm | 10 mm |

**质量与预算余量都很充裕**，因此：
- 主控可从 F103 升级到 G431；
- 电池可用 3S 1500–2200mAh；
- 建议采购：备用电机 1 个、备用相机 1 个、额外电池 1 块。

**宽度余量只有 10mm** —— 这是最紧的一维，且它同时决定推板宽度。
装配时优先保证宽度不超。

## 6. 明确砍掉的东西（及理由）

| 砍掉 | 理由 |
|---|---|
| 麦克纳姆轮 | 侧裙推板已消掉其必要性；且不改变车宽 |
| 全局快门相机 | 读字时完全静止 → 无卷帘错位、无运动模糊。省 ¥150–300 |
| 全场挡板 PnP | 远场精度 ±154mm 不可用 |
| 激光测距 | 明亮场馆不可见；滤光片会废掉视觉通道；标定漂移风险 |
| 自研 PCB | 3 个月来不及打样调试 |
| 移动中读汉字 | 透视压缩 + 卷帘 + 模糊三杀 |
| 翻面机构 | 3D 打印 + 3 个月内不现实（应对 Q2 靠策略降级，不靠机构） |
| 磁力计 | 室内电机磁场干扰大 |
| 任何无线模块 | C11 禁止遥控，含调试用蓝牙/WiFi |
