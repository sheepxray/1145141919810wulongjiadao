# STM32G474VE ↔ TB6612(D24A) 引脚规划与 CubeMX 配置（已按数据手册核对）

> 本表针对 **4×MG513X + TB6612 四路 D24A(带稳压) + STM32G474VET6(LQFP100)**。
> AF 号全部按 ST《STM32G474xB/xC/xE 数据手册》Table 13（Alternate function）核对。
> 本文件是新方案，与 `hardware/electrical/接口定义.md` §2 的差异见文末「待改点」。
> ⚠️ 板载外设（LCD/OLED/CAN/USB/SPI Flash/拨码/LED/蜂鸣器）以 M 板原理图为准，最终仍需在 CubeMX 点一遍。

| 连接 | 说明 |

### 2.4 编码器（4 路，硬件正交解码，无需中断）

| 编码器 | 引脚 | 外设 | AF |
|---|---|---|---|
| 电机 A（E1A/E1B） | PA0 / PA1 | TIM2_CH1/CH2 | AF1 |
| 电机 B（E2A/E2B） | PA6 / PA7 | TIM3_CH1/CH2 | AF2 |
| 电机 C（E3A/E3B） | PB6 / PB7 | TIM4_CH1/CH2 | AF2 |

## 3. CubeMX 配置步骤

1. 选 MCU `STM32G474VETx`（LQFP100）。
2. RCC：外部 HSE（按 M 板晶振），SYSCLK 170 MHz。
3. **TIM1** = PWM Generation，4 通道 CH1-CH4，内部时钟；
   - Prescaler = 0，**Counter Period (ARR) = 16999** → 10 kHz（170M / 17000）；
   - Pulse = 占空比 0–16999；PWM mode 1。
   - 引脚映射：PA8/PA9/PA10 = AF6，PA11 = AF11。
4. **TIM2 / TIM3 / TIM4 / TIM20** = Encoder Mode（Quadrature, TI1+TI2）；
   - Prescaler = 0，Counter Period = 0xFFFF（65535）；两相都 Rising，Filter 0。
   - TIM20 引脚：PE2(CH1)/PE3(CH2)，AF6。
5. **USART1** 异步 TX/RX → PC4/PC5（AF7），115200；**USART2** → PA2/PA3（AF7）921600 + DMA。
6. **SPI2** 主模式 → PB13/14/15/12（AF5），供 ICM-20602。
7. **ADC2** 通道 17（PA4）测电池电压。
8. 其余（LED/蜂鸣器/拨码/STBY/方向）标为 GPIO 输出或输入。
9. 生成工程前用 CubeMX 的 **Pinout 冲突检查** 跑一遍。

### 速度换算（供速度环用）

- MG513X 霍尔 13 线，正交 ×4 = **52 计数/电机转**，减速比 1:28 → **1456 计数/轮转**。
- 3S 电压 12.6→9.0V 同 PWM 轮速变化约 30%，速度环必须闭环。

## 4. HAL 初始化代码骨架（关键片段）

```c
/* motor.h */
typedef enum { MOTOR_A, MOTOR_B, MOTOR_C, MOTOR_D } MotorId;
typedef enum { CW, CCW } Dir;

void motor_set(MotorId m, Dir d, uint16_t pwm);   /* pwm: 0..16999 */
void motor_stop(MotorId m);
void motor_standby(uint8_t on);                   /* on=1 使能 */
int32_t enc_get(MotorId m);

/* motor.c 引脚宏（与 §2 对应） */
#define TIM_PWM   (&htim1)   /* CH1=A CH2=B CH3=C CH4=D */
#define ENC_A     (&htim2)
#define ENC_B     (&htim3)
#define ENC_C     (&htim4)
#define ENC_D     (&htim20)

void motor_set(MotorId m, Dir d, uint16_t pwm)
{
    uint32_t ch = TIM_CHANNEL_1 + (uint32_t)m;
    /* 方向：IN1/IN2 由两个 GPIO 给出 */
    switch (m) {
    case MOTOR_A: HAL_GPIO_WritePin(..., d==CW ? 1:0); ... break;
    /* ... A:PB0/PB1  B:PE4/PE5  C:PB10/PB11  D:PD2/PC12 */
    }
    __HAL_TIM_SET_COMPARE(TIM_PWM, ch, pwm);
}

/* TIM1 PWM 初始化核心参数 */
htim1.Init.Prescaler = 0;
htim1.Init.Period     = 16999;   /* 10 kHz */
/* sConfigOC.Pulse = duty; OCMode = TIM_OCMODE_PWM1; */

/* 编码器初始化（TIM2/3/4/20 同构） */
sEnc.EncoderMode   = TIM_ENCODERMODE_TI12;
sEnc.IC1Polarity   = TIM_ICPOLARITY_RISING;
sEnc.IC1Selection  = TIM_ICSELECTION_DIRECTTI;
sEnc.IC2Polarity   = TIM_ICPOLARITY_RISING;
sEnc.IC2Selection  = TIM_ICSELECTION_DIRECTTI;
/* 启动：HAL_TIM_Encoder_Start_IT(&htimx, TIM_CHANNEL_ALL); */
```

> 以上为骨架，CubeMX 生成后按 §2 表格核对 AF 与引脚即可。

## 5. 相对现有 `接口定义.md` 的待改点

1. **调试串口写错**：原「调试 TX=PA14 / RX=PA15」——PA14 是 SWCLK（SWD 必须保留），PA14/PA15 实为 USART2 且与 K230 的 USART2(PA2/PA3) 冲突。→ 改为 USART1 = **PC4(TX) / PC5(RX)**。
2. **BIN1/BIN2 让位**：原 BIN1/BIN2 占用 PC4/PC5，与上面调试串口冲突。→ 方向线改 **BIN1/BIN2 = PE4/PE5**。
3. **第 4 路编码器确定**：原「待定（TIM5 或 GPIO 中断）」→ 定为 **TIM20 = PE2/PE3（AF6）** 硬件正交解码。
4. **编码器 C 已确认**：PB6/PB7 = TIM4_CH1/CH2（AF2）正确。
5. **电池 ADC 更正**：PA4 实为 **ADC2_IN17**（原写 ADC1_IN4），分压比不变。
6. 其余（PWM=TIM1 PA8-11、编码器 A/B=TIM2/TIM3、IMU=SPI2、STBY=PC6）保留原案。

## 6. 仍须人工核对（依赖 M 板原理图）

- PE2/PE3（TIM20）、PE4/PE5（方向）是否被板载 LCD/FSMC 等占用——若被占用，方向线换任意空闲 GPIO，第 4 路编码器可备选 **TIM5 = PF6(CH1,AF6) / PC12(CH2,AF1)**。
- 蜂鸣器 PB8、拨码 PB3/4/5/PC7、LED PC13 以实际丝印为准。
- **IMU INT 已定为 PB9**（原 PB3 与拨码第 4 路冲突）。若 PB9 被板载资源占用，从空闲脚另选。
