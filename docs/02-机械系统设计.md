## 2. 车架（3D 打印）

### 2.1 结构形式：三板式

```
    上层板 (3mm, z=100)  —— RK3588、H723、IMU
        ↕ 铜柱 32mm
    中层板 (3mm, z=68)   —— BTS7960、电池
        ↕ 铜柱 20mm
    底板   (4mm, z=44)   —— 电机座、推板挂点、万向球座
```

**为什么用三板**：RK3588 对电源噪声敏感（堵转时 3S 会被拉低 0.75V，
可能导致 brownout 重启）。把视觉/逻辑放上层、动力放中层，
配合 [docs/06](06-电源系统.md) 的电源隔离，是最省空间的抗干扰布局。

### 2.2 ★ 相机立柱（高度计算的关键）

**相机光心高度 150mm 是全部几何计算的基准** ——
挡板可见性、汉字像素数、可见地面区间都基于它（[docs/14](14-1080p视觉管线.md)）。

但三层板顶面在 z=100mm，所以需要一根 **50mm 立柱**把相机举到 150mm。

```
   z=160 ┌──┐  ← 相机顶面（总高限制点）
   z=150 │▓▓│  ← 相机光心 ★ 几何基准
   z=105 │  │  ← 50mm 立柱
   z=100 └──┘  ← 上层板
```

> ⚠️ **不能为了降低总高而降低相机高度** ——
> 那会改变所有几何计算的结果（可见区间、汉字像素数）。
> 160mm 总高在 180mm 限值内，余量 20mm。

### 2.3 打印规范

| 项目 | 规范 | 理由 |
|---|---|---|
| 材料 | **PETG**（承力件可 PA-CF / ASA） | **不要 PLA** —— 脆，冲击下会断 |
| 层高 | 0.2mm | 强度/时间平衡 |
| 壁数 | ≥ 3 层 | 壁数比填充率更影响强度 |
| 填充 | 25%（承力件 40%） | — |
| 螺纹 | **全部用热熔铜螺母** | 打印螺纹孔会滑丝 |
| 螺丝 | 金属 M3（不锈钢） | — |

**三点必须注意**：

1. **受载方向决定打印朝向** —— 推板挂点、电机座要按受力方向摆放模型，
   让层间结合面**垂直于**主受力方向（FDM 的层间强度远低于层内）。
2. **悬臂结构加筋** —— 推板是悬臂，必须加三角筋或做成箱型截面。
3. **热熔铜螺母孔径** —— PETG 用 M3 铜螺母时孔径取 4.0–4.2mm。

## 3. 推板机构（本设计的核心）

### 3.1 为什么是"盒式"而不是"一块弧形板"

| 问题 | 后果 | 盒式结构的解法 |
|---|---|---|
| 车体偏航时棋子从侧面滑出 | 推一半丢了 | **侧裙**（高 30mm）把棋子兜在开口内 |
| 棋子从推板底下钻过去 | 完全失效 | **柔性贴地**，离地 ≤1.5mm 且有下压力 |

### 3.2 ★ 关键洞察：容错窗口与车宽无关

棋子贴侧墙时，车体横向可用的对准窗口：

```
约束 (a) 推板要罩住棋子 : car_y − jaw_half ≤ r        （r = 棋子半径 22.5mm）
约束 (b) 车体不能撞墙   : car_y ≥ car_half + clearance

窗口 = (r + jaw_half) − (car_half + clearance)
```

**若推板不超出车体**（`jaw_half = car_half`），车体半宽被消掉：

```
窗口 = r − clearance = 22.5 − 5 = 17.5mm   （与车宽无关！）
```

`tools/geometry.py` 实测：推板开口从 150mm 排到 200mm，窗口**恒为 17.5mm**。
**把车体做宽对贴墙容错毫无帮助。**

**让推板比车体宽**才是正确杠杆。设悬伸 `overhang = jaw_half − car_half`：

```
窗口 = r + overhang − clearance
```

| 车体宽 | 推板宽 | 悬伸 | 窗口 | 评价 |
|---|---|---|---|---|
| 190mm | 195mm | 2.5mm | 20.0mm | 困难 |
| 170mm | 195mm | 12.5mm | 30.0mm | 可行 |
| **150mm** | **195mm** | **22.5mm** | **40.0mm** | **可行** |

**决策：车体宽 150mm，推板宽 195mm → 容错窗口 40.0mm。**

### 3.3 几何参数表

| 参数 | 取值 | 依据 |
|---|---|---|
| 推板总宽 | 195mm | 接近 200mm 外廓上限 |
| 开口宽度 | 165mm | 两侧各留 15mm 做侧裙与结构 |
| 单侧容错（对中） | ±82.5mm | 开口/2 |
| **单侧容错（贴墙）** | **40.0mm** | 见 3.2 推导 |
| 侧裙高度 | 30mm | 高于棋子平躺侧影 |
| 侧裙离地 | 1.5mm | 配合柔性下压 |
| 推板倾角 | 0°（垂直） | 弧形前缘做内凹利于自定心 |

### 3.4 柔性贴地

**这是最容易做坏的一环。** 推板一旦抬起 5mm，棋子从底下溜走，整个机构白设计。

| 要点 | 做法 |
|---|---|
| 弹簧预压 | 2 个压簧（k≈0.5 N/mm），预压 8mm → 约 4N 下压力 |
| PTFE 贴底 | 底面粘 0.5mm PTFE 胶带减摩 |
| 机械限位 | 最低点离地 1.5mm，避免弹簧压到地面刮擦 |
| 铰接 | 通过横向转轴悬挂，只保留俯仰自由度 |

### 3.5 验证方法（M1 必做）

| 测试 | 通过标准 |
|---|---|
| 贴地测试：推板压过一张纸 | 纸被推动，不被压住 |
| 侧裙测试：斜 30° 推一枚棋子 | 棋子在开口内被带向中心，不侧向逃逸 |
| **贴墙测试**：棋子靠墙，车贴墙推 | 能推走。记录实际可容忍的横向偏差 |

**第三项决定"贴墙纵推模式"能否使用。**

## 5. 相机安装

| 相机 | 位置 | 朝向 | 任务 |
|---|---|---|---|
| 前视 | 车头，**立柱顶 z=150** | **俯角 15°** | 搜索棋子、近场测墙、障碍 |
| 下视 | 推板正上方，**立柱顶 z=150** | **俯角 60°** | 停车读字、推入段伺服 |

### 下视相机为什么是 60° 而不是 90°

`tools/geometry.py` 暴露的设计陷阱：相机高 150mm、**垂直下视**时，
可见地面区间只有 **0–76mm** —— 画面只覆盖车体正下方，
**完全看不到推板前方 100–250mm 处的棋子**。

| 俯角 | 可见地面区间 | 250mm 处汉字可读性 |
|---|---|---|
| 89°（垂直） | 0 – 76mm | 该距离**不在视场内** |
| **60°** | **11 – 222mm** | 径向 113.6px（舒适） |
| 45° | 52 – 434mm | 舒适，但地面压缩更明显 |

**决策：俯角 60°，用打印的角度定位块保证。**

## 6. SketchUp 建模

模型由 [`tools/sketchup_model.py`](../tools/sketchup_model.py) **参数化生成**，
输出 SketchUp Ruby 脚本到 [`hardware/mechanical/sketchup/build_robot.rb`](../hardware/mechanical/sketchup/build_robot.rb)。

### 为什么用生成器而不是手写模型

五轮迭代中尺寸改过多次（车宽、推板、主控、相机）。
参数化后**改一个数字就能重新生成整套模型**，而不是维护一份会过时的死图。

### 使用方法

```bash
python tools/sketchup_model.py          # 校验尺寸 + 生成 Ruby 脚本
python tools/sketchup_model.py --layout # 只看三视图
```

在 SketchUp 2026 中：

```
方式1: 窗口 → Ruby 控制台 → 粘贴脚本全文 → 回车
方式2: 扩展程序 → Ruby 控制台 → load '<路径>/build_robot.rb'
```

### 模型包含

| 组 | 说明 |
|---|---|
| `BasePlate` / `MidPlate` / `TopPlate` | 三层板 |
| `Wheel_L` / `Wheel_R` / `Motor_L` / `Motor_R` | 轮系与电机 |
| `Caster_F` / `Caster_B` | 前后万向球 |
| `Jaw_Back` / `Skirt_L` / `Skirt_R` | 盒式推板三件 |
| `CamMast_F` / `CamMast_D` | 相机立柱（50mm） |
| `Cam_Front` / `Cam_Down` | 两个相机 |
| `Battery` / `VisionBoard_RK3588` / `MCU_H723` / `Driver_*` / `Laser` | 电子件占位 |

## 7. 装配顺序

```
1. 底板打印 → 压入热熔铜螺母 → 装电机座
2. 装 2 个驱动轮 + 前后万向球 → 检查四点共面
3. 中层板（铜柱 20mm）→ 装 BTS7960、电源模块
4. 上层板（铜柱 32mm）→ 装 RK3588、H723、IMU
5. 装相机立柱（50mm）→ 装两个相机
6. 装推板：铰接轴 → 弹簧 → 校准离地 1.5mm
7. 称重 → 回填 tools/mass_budget.py
8. 通电自检
```

**第 5 步前不要装推板** —— 推板悬臂会妨碍接线。
**相机角度必须用定位块**，不能目测：俯角误差 5° 会显著改变可见区间。
**第 1 步先装轮子再装板**，方便调整四点共面。

## 8. 待确认项的机械影响

| 待确认项 | 机械影响 |
|---|---|
| Q5 棋子实际直径 | 推板开口、侧裙高度、贴地间隙全部依赖它。**默认按 φ45 设计** |
| Q5 棋子厚度 | 侧裙高度只需高于厚度 |
| Q4 球门位置 | 决定推进轴向，不影响机械本体 |
| 地面材质 | 影响万向球选型（硬地 vs 地毯） |

**若棋子实际直径不是 45mm**：改 `tools/sketchup_model.py` 的参数重跑，
推板几何随之更新。
