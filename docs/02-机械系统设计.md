# 02 · 机械系统设计

> 加工条件：**只有 3D 打印**。因此全部结构件为打印件，无钣金、无激光切割。
> 所有数值都由 `python tools/mass_budget.py` 与 `python tools/geometry.py` 校核。

## 2. 车架（3D 打印）

### 2.1 结构形式：三板式

```
    上层板 (3mm)  —— K230、STM32、IMU
        ↕ 铜柱 25mm
    中层板 (3mm)  —— 驱动模块、电源
        ↕ 铜柱 20mm
    底板   (4mm)  —— 电机座、推板挂点、万向球座
```

**为什么用三板而不是单板**：K230 对电源噪声敏感（堵转时 3S 会被拉低 1–2V，
可能导致 brownout 重启）。把视觉/逻辑放上层、动力放中层，配合 [docs/06](06-电源系统.md)
的电源隔离，是最省空间的抗干扰布局。

### 2.2 打印规范

| 项目 | 规范 | 理由 |
|---|---|---|
| 材料 | **PETG**（承力件可用 PA-CF / ASA） | **不要用 PLA** —— 脆，冲击下会断 |
| 层高 | 0.2mm | 强度/时间平衡 |
| 壁数 | ≥ 3 层 | 壁数比填充率更影响强度 |
| 填充 | 25%（承力件 40%） | — |
| 螺纹 | **全部用热熔铜螺母（heat-set insert）** | 打印螺纹孔会滑丝、且反复拆装会崩 |
| 螺丝 | 金属 M3（不锈钢） | — |

**必须注意的三点**：

1. **受载方向决定打印朝向。** 推板挂点、电机座要按受力方向摆放模型，
   让层间结合面**垂直于**主受力方向（FDM 的层间强度远低于层内）。
2. **悬臂结构加筋。** 推板是悬臂，必须加三角筋或做成箱型截面。
3. **热熔铜螺母要留正确孔径。** PETG 用 M3 铜螺母时，孔径取 4.0–4.2mm，
   用烙铁压入。孔径小了会撑裂，大了会松动。

## 3. 推板机构（本设计的核心）

### 3.1 为什么是"盒式"而不是"一块弧形板"

一块平板推板有两个致命问题：

| 问题 | 后果 | 盒式结构的解法 |
|---|---|---|
| 车体偏航时棋子从侧面滑出 | 推一半丢了 | **侧裙**（高 25–35mm）把棋子兜在开口内 |
| 棋子从推板底下钻过去 | 完全失效 | **柔性贴地**，底面离地 ≤1.5mm 且有下压力 |

### 3.2 关键洞察：容错窗口与车宽无关

这是本设计最重要的一处推导，`tools/geometry.py` 有实跑验证。

棋子贴侧墙时，车体横向可用的对准窗口：

```
约束 (a) 推板要罩住棋子 : car_y − jaw_half ≤ r         （r = 棋子半径 22.5mm）
约束 (b) 车体不能撞墙   : car_y ≥ car_half + clearance

窗口 = (r + jaw_half) − (car_half + clearance)
```

**若推板不超出车体**（`jaw_half = car_half`），车体半宽被完全消掉：

```
窗口 = r − clearance = 22.5 − 5 = 17.5mm   （与车宽无关！）
```

脚本实测：推板开口从 150mm 排到 200mm，窗口**恒为 17.5mm**。
**把车体做宽对贴墙容错毫无帮助。**

**让推板比车体宽**才是正确杠杆。设悬伸 `overhang = jaw_half − car_half`：

```
窗口 = r + overhang − clearance
```

| 车体宽 | 推板宽 | 悬伸 | 窗口 | 评价 |
|---|---|---|---|---|
| 190mm | 195mm | 2.5mm | 20.0mm | 困难 |
| 170mm | 195mm | 12.5mm | 30.0mm | 可行 |
| **150mm** | **195mm** | **22.5mm** | **40.0mm** | **可行** |
| 140mm | 195mm | 27.5mm | 45.0mm | 可行 |
| 130mm | 195mm | 32.5mm | 50.0mm | 可行 |

**决策：车体宽 150mm，推板宽 195mm → 容错窗口 40mm。**

> 代价：车体做窄会压缩内部空间。150mm 宽、190mm 长要放下 K230 + STM32 + 2 个
> BTS7960 + 电池 + 2 个电机。因此采用**三层板**并把电池竖放。若空间实在不够，
> 可放宽到 160mm（窗口仍有 35mm），但**不要超过 170mm**。

### 3.3 几何参数表

| 参数 | 取值 | 依据 |
|---|---|---|
| 推板总宽 | 195mm | 接近 200mm 外廓上限 |
| 开口宽度 | 165mm | 两侧各留 15mm 做侧裙厚度与结构 |
| 单侧容错（对中） | ±82.5mm | 开口/2 |
| 单侧容错（贴墙） | 40mm | 见 3.2 推导 |
| 侧裙高度 | 30mm | 高于棋子平躺侧影（φ45 → 侧影 45mm 直径、厚约 12–15mm） |
| 侧裙离地 | 1.5mm | 配合柔性下压 |
| 推板倾角 | 0°（垂直） | 弧形前缘做 ±30mm 内凹利于自定心 |
| 柔性下压行程 | 8mm | 弹簧预压 |

### 3.4 弧形前缘（自定心）

开口内缘做成**内凹弧形**（半径约 120mm），使棋子接触后被引导向中心：

```
        ╭───── 内凹弧 R120 ─────╮
   ─────┤                        ├─────
        ╰────────────────────────╯
             开口 165
```

配合"下视相机视觉伺服"（见 [docs/07](07-软件架构与决策策略.md)），
弧面提供被动容错、伺服提供主动纠偏，两者叠加。

### 3.5 柔性贴地

**这是最容易被做坏的一环。** 推板一旦抬起 5mm，棋子从底下溜走，整个机构白设计。

实现要点：

1. **弹簧预压**：推板底面通过 2 个压簧（k≈0.5 N/mm）向下压，预压 8mm
   → 常态下压力约 4N，足以刮住棋子又不会顶起车头。
2. **PTFE 贴底**：底面粘 0.5mm PTFE 胶带。棋子是木质/塑料，PTFE 与它们的
   摩擦系数低，但**与地面的摩擦也不是问题**（推板是被车推着走的，不是靠摩擦驱动）。
3. **限位**：加一个机械限位使推板最低点离地 1.5mm，避免弹簧把它压到地面刮擦。
4. **铰接而非刚性**:推板通过一根横向转轴挂在车体上，只保留俯仰自由度。

### 3.6 验证方法（必做）

打印出来后，在平地用**真棋子**做三个测试：

| 测试 | 通过标准 |
|---|---|
| 贴地测试：推板压过一张纸 | 纸被推动，不被推板压住 |
| 侧裙测试：斜向推一枚棋子 | 棋子在开口内被带向中心，不侧向逃逸 |
| 贴墙测试：棋子靠墙，车贴墙推 | 能推走。记录实际可容忍的横向偏差 |

**第三项是决定"贴墙纵推模式"能否使用的关键实验。**

## 4. 质量预算

由 `python tools/mass_budget.py` 生成：

| 类别 | 质量 | 占比 |
|---|---|---|
| 结构（打印件/螺丝/推板） | 385 g | 39.0% |
| 动力（电机/轮/驱动板） | 290 g | 29.4% |
| 电源（电池/稳压） | 203 g | 20.6% |
| 视觉（K230/相机） | 62 g | 6.3% |
| 合规（激光/LED） | 27 g | 2.7% |
| 控制（G431/IMU） | 20 g | 2.0% |
| **合计** | **987 g** | **65.8% of 1500g** |

余量 513g，可支持：备用电池、额外的相机、更结实的打印件（提高填充率）。

> **注意**：以上为预估值。采购后必须用厨房秤逐一称重，回填 `MEASURED` 字典后重跑脚本。

## 5. 相机安装

| 相机 | 位置 | 朝向 | 任务 |
|---|---|---|---|
| 前视 | 车头，中层板前端 | **前下方俯角 15°** | 搜索棋子（颜色 blob）、近场测墙、障碍 |
| 下视 | 推板正上方，上层板 | **垂直向下**（俯角 90°） | 停车读字、推入段伺服 |

### 前视相机安装角的校核

由 `tools/geometry.py`：相机高 150mm、俯角 15°、OV5640+2.8mm（VFOV 51.8°）时：

- 挡板在 0.12m 以外的**全部距离**都可见（画幅上边缘越过水平线）；
- 测距精度：0.5m 处 ±5.2mm，1.0m 处 ±18.5mm，1.5m 处 ±40.1mm；
- **3m 处 ±154.4mm —— 不可用**。

**所以前视相机只用来做 1m 内的近场测墙**，全局定位靠航迹推算（见 [docs/05](05-定位与导航.md)）。

### 下视相机安装角的校核

同脚本：相机高 150mm、垂直下视（俯角 89°）时，可见地面区间为 **0 ~ 76mm**！

**这是一个必须处理的问题**：垂直下视时，画面只覆盖车体正下方 76mm 范围，
而推板在车前方 100–250mm 处。**垂直下视看不到推板前方的棋子。**

两种解法：

| 方案 | 做法 | 取舍 |
|---|---|---|
| **A. 前倾安装**（推荐） | 俯角降到 **60°**，可见区间 **11 ~ 222mm** | 汉字仍有 113.6px（舒适），覆盖推板前方 |
| B. 抬高相机 | 高度增到 300mm | 受总高 180mm 限制，不可行 |

**决策：下视相机俯角取 60°，安装高度 150mm。** 可见地面区间 11–222mm，
覆盖推板开口前方；汉字 20mm 时径向 113.6px、横向 160px，识别余量充足。

> 这是 `tools/geometry.py` 直接暴露出来的一个设计陷阱：
> "垂直下视"听起来合理，但视场覆盖不到推板前方。**必须前倾 30°。**

## 6. 装配顺序

```
1. 底板打印 → 压入热熔铜螺母 → 装电机座
2. 装 2 个驱动轮 + 前后万向球 → 检查四点共面
3. 装中层板（铜柱 20mm）→ 装 BTS7960、电源模块
4. 装上层板（铜柱 25mm）→ 装 K230、STM32、IMU
5. 装推板：先装铰接轴 → 装弹簧 → 校准离地 1.5mm
6. 装相机：前视 15°、下视 60° → 用打印的角度定位块保证角度
7. 称重 → 回填 mass_budget.py
8. 通电自检
```

**第 3 步前不要装推板** —— 推板悬臂会妨碍接线。
**第 6 步的角度必须用定位块**，不能靠目测：俯角误差 5° 会显著改变可见区间。

## 7. 待确认项的机械影响

| 待确认项 | 机械影响 |
|---|---|
| Q5 棋子实际直径 | 推板开口宽度、侧裙高度、贴地间隙全部依赖它。**默认按 φ45 设计** |
| Q5 棋子厚度 | 侧裙高度只需高于厚度 |
| Q4 球门位置 | 决定推进轴向，不影响机械本体 |
| 地面材质 | 影响万向球选型（硬地 vs 地毯） |

**若棋子实际直径不是 45mm，推板几何必须重算** —— 用 `tools/geometry.py` 中的
`wall_hug_window` 函数改参数重跑即可。
