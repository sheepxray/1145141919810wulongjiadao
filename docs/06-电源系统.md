# 06 · 电源系统

---

## 1. 拓扑

```
                    3S LiPo 11.1V (12.6V 满电)
                            │
                      [保险丝 10A]
                            │
              ┌─────────────┼──────────────────┐
              │             │                  │
        [BTS7960 ×2]   [DC-DC 12→5V]     [分压 → ADC]
              │             │                  │
         JGB37-520      [LC 滤波]          电池监测
         ×2（动力轨）        │
                    ┌──────┴──────┐
                    │             │
                [K230]     [DC-DC 5→3.3V]
                [相机]            │
                            [G431 / IMU]
                            （逻辑轨）
```

**核心原则：动力轨与逻辑轨必须隔离，且单点星型接地。**

## 2. 电池

### 2.1 选型：3S LiPo 1500mAh

| 参数 | 取值 |
|---|---|
| 电压 | 3S = 11.1V 标称，12.6V 满电，9.0V 截止 |
| 容量 | 1500mAh → **16.65 Wh** |
| 放电倍率 | 建议 ≥ 25C（即 37A 持续） |
| 质量 | 约 130g |
| 价格 | 约 ¥85 |

### 2.2 功率预算

| 负载 | 典型 | 峰值 |
|---|---|---|
| 2× 电机（行驶） | 12V × 2.0A = **24W** | 12V × 10A = 120W（双堵转） |
| K230（5V） | 2.0W | 3.0W |
| 相机 ×2 | 0.5W | 0.6W |
| STM32 + IMU | 0.3W | 0.4W |
| **合计** | **约 27W** | 约 124W |

**续航核算**：

```
16.65 Wh ÷ 27 W ≈ 0.62 h ≈ 37 分钟
```

比赛单场 3 分钟，**容量余量极大**。

### 2.3 为什么仍然选 1500mAh 而不是更小

容量不是选型理由，**内阻**才是。

3S 1500mAh 电池包内阻约 **100–150 mΩ**。双电机堵转 10A 时：

```
压降 = 10 A × 0.12 Ω ≈ 1.2 V
12.6V → 11.4V
```

这个跌落对电机可接受，但**对 5V 逻辑轨是威胁** —— 见第 4 节的 brownout 风险。

容量更大的电池内阻更低。1500mAh 是"质量（130g）"与"内阻"的平衡点。
**不要为了省 30g 换成 850mAh 的小电池**，那会让压降更严重。

### 2.4 保护

| 措施 | 参数 |
|---|---|
| 保险丝 | **10A** 快断，串在电池正极 |
| 低压报警器 | 阈值 **10.5V**（3.5V/节），插在平衡头上 |
| 防止过放 | 10.5V 报警后仍可完成当前动作 |
| 充电 | IMAX B6 或同级，平衡充 |

> 3S 放到 9.0V 以下会永久损坏。低压报警器是**必须品**，约 ¥10。

## 3. 三路稳压

| 轨 | 输入 | 输出 | 电流 | 供给 |
|---|---|---|---|---|
| **动力轨** | 11.1V | 11.1V 直供 | 峰值 10A | BTS7960 → 电机 |
| **视觉轨** | 11.1V | **5V** | ≥ 3A | K230、相机 |
| **逻辑轨** | 5V | **3.3V** | ≥ 1A | G431、IMU |

### 3.1 视觉轨（5V）要求

| 要求 | 说明 |
|---|---|
| 输出电流 | **≥ 3A**（K230 峰值 + 相机 + 余量） |
| 模块 | 不要用 MP1584（1.5A）/ LM2596（2A）等廉价款 |
| 推荐 | 5A 以上的同步 buck，或 LM2596 并联降额使用 |
| 输入电容 | **≥ 470µF 低 ESR 电解 + 100nF 陶瓷** |

**廉价 MP1584/LM2596 的问题是瞬态响应差** —— 输入跌落 1.2V 时输出会跟着掉，
这正是 K230 brownout 的直接原因。

### 3.2 逻辑轨（3.3V）

STM32 核心板通常自带 LDO，可直接从 5V 取电。
但若 IMU 也在这一轨，注意 SPI 通信的电源噪声，加 10µF + 100nF 去耦。

## 4. ★ K230 Brownout 防护（重点风险）

### 4.1 风险描述

K230 是这套系统里**对电源最敏感、失效后果最严重**的器件：

- 失效后果：视觉全丢 + 串口断链 + 需重启（重启一次 = 一次丢定位）；
- 敏感性：内部需要稳定的 5V → 3.3V → 1.8V 多级。

**触发场景**：电机堵转（顶墙/顶棋子/顶对方车）时，电池被拉低 1–2V，
若 5V buck 瞬态响应不足，**K230 会 brownout 重启**。

### 4.2 防护措施（按优先级）

| 优先级 | 措施 | 说明 |
|---|---|---|
| 🔴 **必须** | 视觉轨与动力轨**分开供电**（各自的 buck） | 不要从 BTS7960 的输出取电 |
| 🔴 **必须** | 视觉 buck 输入加 **≥470µF 低 ESR 电解** | 吸收瞬态跌落 |
| 🔴 **必须** | buck 输出加 **220µF + 10µF + 100nF** | 提供本地储能 |
| 🟡 推荐 | 视觉轨输入串 **铁氧体磁珠 + 电容**（LC 滤波） | 抑制电机 PWM 噪声传导 |
| 🟡 推荐 | 20kHz PWM（不是 1kHz） | 噪声频率远离 buck 带宽 |
| 🟡 推荐 | 视觉轨用**独立的 DC-DC**，不与逻辑轨共用 | 隔离 |
| 🟢 可选 | 逻辑与动力**分电池** | 最彻底，但增加 130g |

### 4.3 软件侧的兜底

即使电源做得再好，也要假设 K230 可能会重启：

1. **心跳检测**：STM32 监控 K230 心跳包（docs/11），超时 200ms 判定失联；
2. **失联即降级**：进降级策略 B（[docs/07](07-软件架构与决策策略.md) §5），不要停在原地；
3. **重启后重同步**：K230 重启后发 `HELLO`，STM32 回送当前状态，恢复协同。

**不要让 K230 的失效导致整车瘫痪** —— 这是设计原则，不是可选项。

## 5. 接地策略：单点星型

```
        ┌──────────── 电池负极（星点）────────────┐
        │              │              │           │
   BTS7960 GND    buck1 GND      buck2 GND   STM32 GND
   （动力地）      （视觉地）      （逻辑地）    （信号地）
```

**为什么重要**：电机电流可达 10A。若地线走成"菊花链"，
动力电流会在地线上产生压降，叠加到信号地上 → 传感器读数漂移、串口误码。

| 规范 | 说明 |
|---|---|
| 单点接地 | 所有地线汇到一个点（电池负极） |
| 动力线加粗 | ≥ 18AWG |
| 信号线远离动力线 | 不要并排走线 |
| 电机端子加 **104 陶瓷电容** | 抑制电刷噪声（有刷电机必做） |
| 电机端子加 **TVS 二极管** | 吸收感性尖峰 |

## 6. 滤波与保护元件清单

| 位置 | 元件 | 作用 |
|---|---|---|
| 电池输出 | 10A 保险丝 | 短路保护 |
| BTS7960 B+ | 1000µF 低 ESR 电解 | 吸收堵转瞬态 |
| BTS7960 B+ | 100nF 陶瓷 | 高频去耦 |
| 每个电机端子 | 104 陶瓷电容 | 电刷噪声 |
| 每个电机端子 | TVS（SMBJ15A） | 感性尖峰 |
| 视觉 buck 输入 | 470µF + 铁氧体磁珠 | 隔离动力噪声 |
| 视觉 buck 输出 | 220µF + 10µF + 100nF | K230 本地储能 |
| 逻辑轨 | 10µF + 100nF | MCU/IMU 去耦 |

**TVS 选型注意**：SMBJ15A 的钳位电压约 24V，高于 BTS7960 的 27V 上限，安全。
若用 12V 以下的 TVS，会在正常工作时就导通。

## 7. 上电时序

```
1. 拨动开关 → 电池接入
2. 逻辑轨先上电（buck 启动快）→ STM32 复位启动
3. STM32 等待 100ms 让电源稳定
4. STM32 拉高 BTS7960 的 EN → 动力轨使能
5. STM32 等待 K230 心跳（最多 3s）
6. 开始自检流程（docs/03 §6）
```

**注意第 4 步**：动力轨**延迟使能**，避免上电瞬间电机抖动导致车体位移
（C6 规定的是发车状态尺寸，但发车时车辆不应移动）。

## 8. 电量监测

STM32 用 ADC 读电池电压（分压到 3.3V 以内）：

```
分压比： 12.6V → 3.0V，取 R1=39kΩ, R2=10kΩ
        V_adc = V_bat × 10/(39+10) = V_bat × 0.204
        12.6V → 2.57V  ✅ 在 3.3V 内
        9.0V  → 1.84V  ✅
```

| 电压 | 判定 | 动作 |
|---|---|---|
| > 11.0V | 正常 | — |
| 10.5–11.0V | 偏低 | 记录，继续 |
| < 10.5V | 低电量 | 蜂鸣器提示（但仍继续比赛） |

**分压电阻要加 100nF 滤波电容**，否则 PWM 噪声会让读数跳动。
