## 3. 电源接口

```
J1 (XT60)
  ├─ +  → 10A 保险丝 → 主配电节点
  └─ −  → 星型接地点（电池负极）

主配电节点
  ├─ BTS7960(L) B+
  ├─ BTS7960(R) B+
  ├─ DC-DC(视觉) IN
  └─ 分压网络 → PA4
```

### 3.1 三路稳压

| 轨 | 模块 | 输出 | 供给 |
|---|---|---|---|
| 动力 | 直供 | 11.1V | BTS7960 → 电机 |
| 视觉 | DC-DC | **5V ≥3A** | K230、相机 |
| 逻辑 | DC-DC / LDO | **3.3V ≥1A** | STM32、IMU |

> ⚠️ K230 的 5V **不要用 MP1584 / LM2596**（瞬态响应差 → brownout）。
> 见 [docs/06](../../docs/06-电源系统.md) §4。

### 3.2 接地（单点星型）

```
        ┌──────── 电池负极（星点）────────┐
        │          │          │           │
   BTS7960 GND  buck1 GND  buck2 GND  STM32 GND
```

**电机电流可达 10A**。地线走成菊花链会让动力电流在信号地上产生压降。

## 4. 必装的滤波与保护元件

| 位置 | 元件 | 作用 |
|---|---|---|
| 电池输出 | 10A 快断保险丝 | 短路保护 |
| BTS7960 B+ | 1000µF 低 ESR 电解 + 100nF 陶瓷 | 吸收堵转瞬态 |
| **每个电机端子** | **104 陶瓷电容** | 电刷噪声（有刷电机必做） |
| **每个电机端子** | **TVS (SMBJ15A)** | 感性尖峰 |
| 视觉 buck 输入 | 470µF + 铁氧体磁珠 | 隔离动力噪声 |
| 视觉 buck 输出 | 220µF + 10µF + 100nF | K230 本地储能 |
| 逻辑轨 | 10µF + 100nF | MCU / IMU 去耦 |
| 电池电压 ADC | 100nF | 滤 PWM 噪声 |

> **TVS 选型**：SMBJ15A 钳位约 24V，低于 BTS7960 的 27V 上限。
> 用 12V 以下的 TVS 会在正常工作时就导通。

## 5. 线序定义

### J4 / J5 编码器（4P）

| Pin | 信号 |
|---|---|
| 1 | VCC 5V |
| 2 | GND |
| 3 | A 相 |
| 4 | B 相 |

> **上电前先用万用表确认 VCC/GND 线序** —— 编码器反接会烧霍尔元件。

### J6 IMU（7P）

| Pin | 信号 |
|---|---|
| 1 | VCC 3.3V |
| 2 | GND |
| 3 | SCK |
| 4 | MISO |
| 5 | MOSI |
| 6 | CS |
| 7 | INT |

### J7 K230 串口（4P）

| Pin | 信号 |
|---|---|
| 1 | 3.3V |
| 2 | GND |
| 3 | STM32_TX → K230_RX |
| 4 | STM32_RX ← K230_TX |

> 交叉连接，**共地必须接**。

### J9 激光（3P）

| Pin | 信号 |
|---|---|
| 1 | 5V |
| 2 | GND |
| 3 | 使能（可选） |

> 串联限流电阻，实测功率 **≤0.7mW**。

## 6. 上电前检查清单

- [ ] 万用表测电池极性，确认无反接
- [ ] 测各路稳压输出（空载）：5V ±0.2V，3.3V ±0.1V
- [ ] 确认编码器 VCC/GND 线序
- [ ] 确认 TVS 方向（阴极接正）
- [ ] 确认电解电容极性
- [ ] 确认所有 GND 汇到星点
- [ ] **确认板上无任何无线模块**
