## 2. STM32G474 引脚分配

> ✅ **2026-09-29 已用 CubeMX 校验**，与已编译通过的固件工程
> [`firmware/stm32/wulong_fw/`](../../firmware/stm32/wulong_fw/) 完全对齐。
> 权威口径见
> [STM32G474_TB6612_引脚规划.md](../../firmware/stm32/docs/STM32G474_TB6612_引脚规划.md)
> 与固件导出的 [引脚分配表.md](../../firmware/stm32/wulong_fw/docs/引脚分配表.md)。

### 2.1 电机驱动（D24A）

| 信号 | 引脚 | 外设 | 说明 |
|---|---|---|---|
| PWMA | PA8 | TIM1_CH1 | **10 kHz** |
| PWMB | PA9 | TIM1_CH2 | 10 kHz |
| PWMC | PA10 | TIM1_CH3 | 10 kHz ⚠️ |
| PWMD | PA11 | TIM1_CH4 | 10 kHz ⚠️ |
| AIN1 / AIN2 | PB0 / PB1 | GPIO | 方向 |
| BIN1 / BIN2 | **PE4 / PE5** | GPIO | 方向（PC4/PC5 已让位给调试串口） |
| CIN1 / CIN2 | PB10 / PB11 | GPIO | 方向 |
| DIN1 / DIN2 | PD2 / PC12 | GPIO | 方向 |
| **STBY** | PC6 | GPIO | **高电平使能；★ 软急停** |

> **STBY 必须为高**，否则 4 路全部不转。**推荐由 GPIO 控制**（而不是跳线帽常高），
> 这样堵转保护/急停能真正切断输出。

### 2.2 编码器（4 路正交解码）

| 信号 | 引脚 | 外设 |
|---|---|---|
| 编码器 A | PA0 / PA1 | TIM2_CH1/CH2 |
| 编码器 B | PA6 / PA7 | TIM3_CH1/CH2 |
| 编码器 C | PB6 / PB7 | TIM4_CH1/CH2 |
| 编码器 D | **PE2 / PE3** | TIM20_CH1/CH2 |

> ✅ **第 4 路已定死**：用 **TIM20（PE2/PE3，AF6）** 硬件正交解码，
> 比 GPIO 双沿中断 + 软件解码更省事也更稳。
> 注意不要用 TIM8：TIM8_CH1=PC6（已被 STBY 占用）、CH2=PC7（拨码占用）。

### 2.3 IMU（SPI2）

| 信号 | 引脚 |
|---|---|
| SCK | PB13 |
| MISO | PB14 |
| MOSI | PB15 |
| CS | PB12 |
| INT | **PB9**（原 PB3 与拨码第 4 路冲突，已改） |

> ⚠️ **修正记录**：原设计把 IMU 放在 SPI1（PA5/PA6/PA7），
> 但 **PA6/PA7 与 TIM3 编码器引脚冲突**。已改到 SPI2。

### 2.4 通信

| 信号 | 引脚 | 外设 | 说明 |
|---|---|---|---|
| K230 UART TX | PA2 | USART2_TX | 921600 |
| K230 UART RX | PA3 | USART2_RX | |
| 调试 TX | **PC4** | USART1_TX | **有线**，禁无线（原写 PA14，实为 SWCLK） |
| 调试 RX | **PC5** | USART1_RX | （原写 PA15） |

### 2.5 人机与监测

| 信号 | 引脚 | 说明 |
|---|---|---|
| 拨码开关 ×4 | PB4 / PB5 / PC7 / PB3 | 队伍编号 / 球门侧配置（DIP1-4） |
| 自检 LED | PC13 | 状态指示 |
| 蜂鸣器 | PB8 | 故障报警 |
| 电池电压 | PA4 | **ADC2_IN17** ← 接 D24A 的 `ADC` 引脚（板内已 1/11 分压） |
| SWD | PA13 / PA14 | 下载调试 |

> ⚠️ **电池采样接线变了**：D24A 板载 **10k/1k = 1/11 分压**，
> 直接接 STM32 的 ADC 引脚即可，**不需要**再自己搭分压网络。
> 量程：12.6 V → 1.15 V；9.0 V → 0.82 V。
> 若嫌 ADC 分辨率不足，可改用内部参考或自行加分压（但要复核耐压）。

## 3. 电源架构（★ 已按 D24A 实际情况修正）

### 3.1 三轨（保持原设计，与 D24A 的对外输出无关）

```
3S 电池 (XT60)
  ├─[主保险丝 15A，待实测]→ D24A Vin+  ─┬─ 4× MG513X 电机（VM）
  │                                     ├─ RT8279 → 5V ─┬─ TB6612FNG ×2 的 VCC(20)
  │                                     │               └─ RT9013 → 3.3V 对外（实验/备用）
  │
  └────────────────────→ 独立 DC-DC 5V ≥3A ── K230D + OV5640
```

| 轨 | 模块 | 输出 | 供给 |
|---|---|---|---|
| 动力 | 直供 | 11.1–12.6 V | D24A VM → 4 电机 |
| **视觉** | **独立 DC-DC** | **5 V ≥3 A** | **K230D、相机** |
| 逻辑 | D24A 板载 RT9013 | 3.3 V ≤500 mA | STM32、IMU、拨码 |

### 3.2 过温保护的实际作用范围（已核对原理图）

> 过温网络 `R3(6.8 kΩ NTC) + R4 + R5(0 Ω)` → `P_EN` → **只接 RT8279(U1) 的 EN 脚**。

**它关断的是 D24A 自己那两路「对外实验电源」（5V 及其派生的 3.3V），
不会去切断 VM（电机动力），也不会切断 K230D 的独立供电轨。**

```
四路电机长时间堵转 → 驱动板升温 → P_EN 拉低
  → RT8279 停止 → 板载 5V/3.3V 对外输出失电
  → ⚠️ 连带影响：TB6612FNG 的 VCC(20) 也取自这路 5V
     → 芯片失去内部逻辑供电 → 输出级关断 → 四轮失控滑行
  → 但 K230D（独立 buck）与视觉链路**不受影响**
```

> **结论**：视觉独立供电与这条保护**本来就无关**，无需为此改动；
> 真正的风险是 **TB6612 的 VCC 依赖板载 5V**，以及**堵转发热**本身。
> 处置仍是**堵转降 PWM / 限流**（见 [docs/03 §5](../../docs/03-电控与驱动系统.md)）。
> 可选加强项：把逻辑 3.3V 改为独立 LDO/buck，使 STM32 也完全免疫。

### 3.3 3.3V 轨的容量核对

| 负载 | 电流 |
|---|---|
| STM32G474 核心板 | ~80 mA |
| ICM-20602 IMU | ~5 mA |
| 拨码 / LED / 蜂鸣器 | ~20 mA |
| **合计** | **≈105 mA** |

> RT9013 提供 **500 mA**，余量 4.8 倍 ✅ 充足。
> ⚠️ 但**不要**把 K230D 的 3.3V 也接上来（K230D 由独立 5V 供电）。

### 3.4 接地（单点星型）

```
        ┌──────── 电池负极（星点）────────┐
        │          │          │           │
   D24A GND   独立buck GND  STM32 GND   IMU GND
```

**四路电机堵转电流合计可达 12.8 A（保守读数 3.2 A 档）**。
地线走成菊花链会让动力电流在信号地上产生压降。

## 4. 必装的滤波与保护元件

| 位置 | 元件 | 作用 |
|---|---|---|
| 电池输出 | **15 A 快断保险丝**（待实测调整） | 短路保护 |
| D24A 输入 | 板载 TVS（SMAJ15A）+ 反接保护（V1.1） | ✅ 已有 |
| D24A 输出 | 板载 220 µF ×2（每片驱动） | ✅ 已有 |
| **每个电机端子** | **104 陶瓷电容** | ⚠️ **板上没有，必须自己加**（有刷电机电刷噪声） |
| 视觉 buck 输入 | 470 µF + 铁氧体磁珠 | 隔离动力噪声 |
| 视觉 buck 输出 | 220 µF + 10 µF + 100 nF | K230D 本地储能 |
| 逻辑轨 | 10 µF + 100 nF | MCU / IMU 去耦 |
| 电池电压 ADC | 100 nF | 滤 PWM 噪声 |

> ⚠️ **电机端 RC 是唯一需要自己补的滤波**：D24A 板上有 TVS 和输出电容，
> 但**没有电机端子上的 104 电容**。有刷电机的电刷噪声只能靠它压住。

### 5.3 编码器上电前检查

| Pin | 信号 |
|---|---|
| VCC | 3.3–5 V |
| GND | GND |
| A 相 | 编码器输入 |
| B 相 | 编码器输入 |

> **上电前先用万用表确认 VCC/GND 线序** —— 编码器反接会烧霍尔元件。
> 验证方法：给电机通电让其转动，万用表测 GND 与 A/B 相之间电压，
> 正常应为 **1.6–1.8 V 的波动**（与转速无关）。

### 5.4 K230 串口（4P）

| Pin | 信号 |
|---|---|
| 1 | 5V（**不要**用来给 STM32 供电） |
| 2 | RXD ← 接 STM32 的 **PA2**（USART2_TX） |
| 3 | TXD → 接 STM32 的 **PA3**（USART2_RX） |
| 4 | GND |

> ⚠️ **线序按立创庐山派 Lite-K230D 官方定义**（GH1.25-4P 座子丝印
> `5V / RXD / TXD / GND`），**不是**早前写的 `3.3V / GND / TX / RX`。
> 官方来源：立创开发板 wiki 的引脚查询工具数据层。
>
> - 对应 K230D 的 **UART2 = GPIO11(TXD) / GPIO12(RXD)**（官方推荐串口）
> - **UART0（GPIO38/39）被系统 RT-Smart 占用作调试台，CanMV 固件下不可用**
> - TX/RX 交叉、**共地必须接**；IO 电平 3.3V
> - K230D 由独立 DC-DC 5V 供电，两边只连 GND（见 §3.1）

## 6. 上电前检查清单

- [ ] 万用表测电池极性，确认无反接（⚠️ 早期版本无保护，V1.1 有）
- [ ] 确认 D24A 板版本（板上 "1.1" 丝印）
- [ ] 测板载 5V（±0.5 V）与 3.3V（±0.3 V）
- [ ] 确认 K230D 走独立 DC-DC（原设计如此，复核即可）
- [ ] 确认 4 路编码器 VCC/GND 线序
- [ ] 确认 STBY 已拉高（或已接 GPIO 并使能）
- [ ] 确认 PWM 频率设为 10 kHz
- [ ] **确认每个电机端子上焊了 104 电容**
- [ ] 确认电解电容极性
- [ ] 确认所有 GND 汇到星点
- [ ] **确认板上无任何无线模块**
- [ ] 整车称重 ≤ 1500 g（4 电机已占 680 g）
