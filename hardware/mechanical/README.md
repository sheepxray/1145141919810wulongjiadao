## ⚠️ 打印注意事项

### 1. 打印朝向

FDM 的**层间结合强度远低于层内**。受载件的摆放方向必须让层间结合面
**垂直于主受力方向**。

| 件 | 主受力方向 | 摆放 |
|---|---|---|
| 推板主体 | 水平推力（前后向） | 侧躺打印，使层线垂直于推力 |
| 推板加强筋 | 悬臂弯矩 | 沿长度方向打印 |
| 电机座 | 扭矩 | 座面贴平台 |

### 2. 材料

| 材料 | 用 |
|---|---|
| ✅ **PETG** | 首选，韧性好、耐冲击 |
| ✅ PA-CF / ASA | 承力件可选，强度更高 |
| ❌ **PLA** | **不要用** —— 脆，冲击下会断 |

### 3. 热熔铜螺母

**全部螺纹连接用热熔铜螺母，不要直接攻丝或打印螺纹。**

| 项目 | 参数 |
|---|---|
| 孔径 | **4.0–4.2 mm**（M3 铜螺母，PETG） |
| 工具 | 电烙铁 + 铜螺母压头 |
| 温度 | 约 240°C |

孔径小了会把件撑裂，大了会松动。

### 4. 壁数优先于填充率

**壁数 ≥ 3** 对强度的影响大于提高填充率。承力件可同时做到壁数 4 + 填充 40%。

## 装配顺序

```
1. 底板压入热熔铜螺母 → 装电机座
2. 装 2 驱动轮 + 前后万向球 → 检查四点共面（塞尺）
3. 中层板（铜柱 20mm）→ 装 BTS7960、电源模块
4. 上层板（铜柱 25mm）→ 装 K230、STM32、IMU
5. 装推板：铰接轴 → 弹簧 → 校准离地 1.5mm
6. 装相机：前视 15°、下视 60°（用打印的定位块）
7. 称重 → 回填 tools/mass_budget.py 的 MEASURED
8. 通电自检
```

**第 3 步前不要装推板** —— 悬臂会妨碍接线。

**第 6 步的角度必须用定位块**，不能目测。俯角误差 5° 会显著改变可见地面区间。

## 推板验证测试（M1 必做）

| 测试 | 方法 | 通过标准 |
|---|---|---|
| 贴地 | 推板压过一张纸 | 纸被推动，不被压住 |
| 侧裙 | 斜 30° 推一枚棋子 | 棋子在开口内被带向中心，不侧向逃逸 |
| 贴墙 | 棋子靠墙，车贴墙推 | 能推走；记录可容忍的横向偏差 |

**第三项决定"贴墙纵推模式"能否使用。**

## 待确认项的影响

**若棋子直径不是 φ45mm**：用 `tools/geometry.py` 的 `wall_hug_window`
函数改参数重跑，推板开口与侧裙高度随之更新。
