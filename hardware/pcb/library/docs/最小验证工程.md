# 最小验证工程

本目录提供 KiCad 工程库表模板。最小验证的目标不是画完整载板，而是确认：

1. 两个符号库能被 KiCad 加载。
2. 两个封装库能被 KiCad 加载。
3. 模块符号的引脚号与封装焊盘号一致。
4. 原理图能导出网表。

## 方法一：在现有工程中挂载

把本目录的 `sym-lib-table` 和 `fp-lib-table` 内容合并到目标 KiCad 工程的同名文件，
或使用 KiCad 的库管理器添加：

- 符号库：`wulong_modules`、`wulong_foundation`
- 封装库：`wulong_modules`、`wulong_foundation`

库表使用 `${KIPRJMOD}`，因此要求把库目录放在工程目录内，或按实际路径修改 URI。

## 方法二：建议的最小原理图骨架

新建一个 KiCad 工程，按下列模块放置：

1. `J1`：`Connector_Generic:Conn_01x02`，标记为 `3S_BAT`
2. `U1`：`wulong_modules:TB6612_D24A`
3. `U2`：`wulong_modules:STM32G474VET6_CoreBoard`
4. `U3`：`wulong_modules:K230D_LushanPai_Lite`
5. `PS1`：`wulong_modules:DC_DC_3V3_5V_Module`
6. `CAM1`：`wulong_modules:OV5640_Camera_Module`
7. `M1`–`M4`：`wulong_modules:MG513X_Motor_Encoder`

## 检查顺序

1. 放置模块后先保存，确认库符号能正常实例化。
2. 运行 `检查 → 电气规则检查（ERC）`。
3. 导出网表：`文件 → 导出 → 网表`。
4. 在 PCB 编辑器中更新 PCB，确认每个模块封装都能被找到。
5. 对 D24A、G474、K230D 三块板先用 Placeholder 封装做布局，实物测量后再替换。

## 已知 ERC 预期

本库是模块级库，模块内部的去耦、限流和上拉不会画在符号里。ERC 出现下列
提示属于预期：

- 模块电源引脚缺少去耦电容。
- 未连接的空闲引脚。
- 未连接的网络标签。

真正需要修正的是：

- 同一网络被两个电源输出脚同时驱动。
- 信号方向接反。
- 引脚号与封装焊盘号不一致。
