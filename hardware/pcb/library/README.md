# 乌龙驾到 KiCad 模块库

面向本项目实际到货硬件的模块级 KiCad 库。第一版目标是让原理图能直接画起来，
并把“官方资料尺寸”和“实物复核尺寸”分开标注，避免把未核对尺寸当成已验证封装。

## 目录

| 路径 | 内容 |
|---|---|
| `wulong_modules.kicad_sym` | 模块级原理图符号：主控板、驱动板、视觉板、电源、相机、电机、连接器等 |
| `wulong_foundation.kicad_sym` | 基础器件符号：保险丝、TVS、电容、电感、LED、蜂鸣器、拨码等 |
| `wulong_modules.pretty` | 模块级封装：排针、端子、安装孔及待复核的模块外形 |
| `wulong_foundation.pretty` | 基础器件封装 |
| `sym-lib-table` | 本目录的 KiCad 符号库表 |
| `fp-lib-table` | 本目录的 KiCad 封装库表 |
| `docs/器件核对表.md` | 引脚、封装、尺寸及复核状态 |
| `docs/最小验证工程.md` | 用本库搭建最小原理图的步骤与网络表；本次交付未生成实际 `.kicad_sch` |

## 使用方式

把 `sym-lib-table` 和 `fp-lib-table` 复制到 KiCad 工程目录，或在
KiCad 的“管理符号库 / 管理封装库”中添加这两个文件。库表使用
`${KIPRJMOD}`，因此工程目录中的相对路径可以直接生效。

## 复核状态

- `official`：来自厂商官方封装/手册资料，已按资料建库，但尚未逐项比对实物。
- `datasheet`：来自器件手册或采购规格，封装尺寸明确。
- `placeholder`：模块外形尺寸尚未核实，仅用于原理图/早期布局占位。
- `verified`：已与实物或卡尺测量结果逐项核对。

当前没有任何封装标记为 `verified`。D24A 的排针坐标来自 WHEELTEC 官方封装 JSON，
但仍建议在焊接定制载板前用实物和原理图复核针脚编号与丝印。

## 第一版覆盖范围

- STM32G474VET6 核心板（按本项目 40 个有效引脚建符号，封装为待复核）
- TB6612 D24A 四路驱动带稳压板（含 4 路电机、4 路编码器、电源、ADC、STBY）
- 庐山派 Lite-K230D CanMV 视觉板（UART2、5V、扩展接口）
- DC-DC 多路 3.3V/5V 电源模块（输入、5V、3.3V、GND）
- OV5640 相机模块（DVP 控制 + 电源）
- MG513X 电机 + 霍尔编码器（电机端子、编码器端子）
- XT60、JST-XH、KF301、2.54 排针/排母、安装孔
- 保险丝、TVS、电解电容、104 电容、电感、磁珠、LED、蜂鸣器、拨码、电阻

## 已知限制

1. STM32G474VET6 核心板的排针排列、板宽、安装孔位置尚未用实物确认。
2. K230D 底板的外形与安装孔尺寸尚未用实物确认。
3. DC-DC 多路电源模块的接口位置以资料和常见模块为准，未逐项测实物。
4. OV5640 模块的接口以常见 DVP 模块封装和本项目接口定义为准。
5. D24A 的官方封装 JSON 为嘉立创 EDA 格式，本库只提取了可核对的接口信息，
   没有直接转换整个 JSON。

## 建议的下一步

1. 到货后用卡尺测量三块板：G474 核心板、K230D、DC-DC 模块。
2. 拍一张正面照和一张底面照，记录每个连接器的针脚顺序。
3. 用测量结果更新 `docs/器件核对表.md` 中的复核状态。
4. 在 KiCad 中打开 `docs/最小验证工程.md` 所述的库表，先跑一次 ERC 和封装预览。
