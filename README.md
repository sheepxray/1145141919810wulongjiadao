## 一句话方案

一台 **全向底盘（60mm 麦轮 ×4 + 4×MG513X 电机）** 智能车，前装 **盒式推板（带侧裙）**，
用 **单支 OV5640 前视相机** 做搜索与读字，由 **庐山派 Lite-K230D(128M) 视觉平台**
与 **STM32G474VET6 运动主控** 双核协同，全程自主完成
“搜索 → 识别字符 → 计算优先级 → 两段式接近 → 闭环/开环推入 → 撞墙重定位”。

## 已确认仍有效的设计结论

1. 贴墙容错窗口与**车宽无关**，只取决于“窄车体 + 宽推板 + 悬伸”
   （[00 判断三](docs/00-赛题解读与关键结论.md)）。
2. 挡板测距 `d=H·f/Δy` **不能无条件用**；俯角≠0 时误差可达 17.3% → 用完整投影数值反解
   （[00 §3](docs/00-赛题解读与关键结论.md)、`tools/geometry.py`）。
3. 读字优先级要用**期望值**而非 argmax（[15](docs/15-字符识别与优先级算法.md)）。
4. 实际硬件是 **4×MG513X（1:28）+ TB6612 四路（D24A）**，车速 0.94 m/s 高于 0.8 m/s 目标；
   **最大风险是四路堵转把 TB6612 推到热保护**（3.2 A 档两片合计 20.5 W），
   处置是堵转降 PWM/限流（[17](docs/17-实际电机参数核对.md) §4.3）。
