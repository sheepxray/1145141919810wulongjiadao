# 电机 Bring-up 测试

> 对应固件：`Core/Src/main.c`（测试代码位于 `USER CODE` 区）。
> 目标：在车轮架空的前提下，逐路验证 D24A → MG513X 的方向、PWM、
> 编码器、STBY 软急停和电池采样。

## 1. 安全默认值

固件上电后：

- `STBY = 低`，D24A 四路输出全部关闭；
- 四路 PWM compare 全部为 `0`；
- 不自动转动任何电机；
- 串口测试命令有硬上限：占空比 `300‰`，持续时间 `5000 ms`；
- 命令超时或收到 `S` / `E` 后立即回零并拉低 `STBY`。

> 测试时必须把车轮架空。不要带载落地做第一轮 bring-up。

## 2. 串口接线

调试串口为 `USART1 = PC4(TX) / PC5(RX)`，`115200 8N1`。

PWLINK2 自带串口代理转发能力，可用其 `TX / RX / GND`：

| PWLINK2 | STM32G474 | 说明 |
|---|---|---|
| `RX` | `PC4` | PWLINK2 接收 STM32 发出的数据 |
| `TX` | `PC5` | PWLINK2 向 STM32 发送命令 |
| `GND` | `GND` | 必须共地 |

- IO 参考电压选 `3.3 V`；
- 不要用 PWLINK2 的 `5V` 给已经由 D24A 供电的 STM32 反灌；
- 如果 PWLINK2 的虚拟串口在设备管理器里有黄叹号，先用 PowerWriter 客户端
  修复 USB 串口驱动，再打开对应 COM 口。

## 3. 烧录与连接

1. 接好 D24A 的 `Vin+ / -`、电机 A-D、编码器 A-D、`STBY=PC6`。
2. 先不接电机动力，测量 D24A 的 `5V` 和 `3.3V` 是否正常。
3. 用 PWLINK2 通过 SWD 烧录 `MDK-ARM/wulong_fw/wulong_fw.hex`。
4. 烧录后打开 115200 串口，应看到：

```text
WULONG motor test ready
Default: STBY low, all PWM=0. Type H for help.
```

5. 发送 `H`，确认命令表打印正常。

## 4. 串口命令

| 命令 | 作用 |
|---|---|
| `H` | 打印命令表 |
| `ARM` | 拉高 `STBY`，允许显式 `RUN` |
| `DISARM` | PWM 回零，拉低 `STBY` |
| `S` / `STOP` | 立即停止并解除使能 |
| `E` / `ESTOP` | 软件急停，等同停止 |
| `A+` / `A-` 到 `D+` / `D-` | A-D 路快速点动，默认 `10%`、`800 ms` |
| `A+ 1500` | A 路正转 `10%`、`1500 ms` |
| `A+ 15 1500` | A 路正转 `15‰`、`1500 ms` |
| `RUN A + 15 1500` | 显式测试，必须先 `ARM` |
| `P` / `1` | A 路正转 10%、800 ms（兼容逐字符串口工具） |
| `F` | A 路 **100% 正转、2000 ms**；架空车轮专用，硬超时后立即停止 |
| `N` / `2` | A 路反转 10%、800 ms（兼容逐字符串口工具） |
| `3` / `4` | B 路正转 / 反转，10%、800 ms |
| `5` / `6` | C 路正转 / 反转，10%、800 ms |
| `7` / `8` | D 路正转 / 反转，10%、800 ms |
| `T` | 自动依次测试 A+ A- B+ B- C+ C- D+ D-，并打印每步编码器增量 |
| `W` | 四轮同时逻辑正转、20% 占空比，持续行驶直到 `S/E` |
| `X` | 四轮同时逻辑反转、20% 占空比，持续行驶直到 `S/E` |
| `K1` | 按下后自动执行：前进 20cm → 原地左转 → 后退 20cm → 原地右转 |
| `K2` | 按下后四轮按右移组合运行 2 秒，到时自动停车 |
| `K3` | 已禁用（放弃横向平移方案） |
| `Q` | 打印 A/B/C/D 四路编码器计数 |
| `ENC` | 打印 A-D 四路编码器当前计数 |
| `Z` | 四路编码器计数清零 |
| `V` | 打印电池电压（mV，按 1/11 分压换算） |
| `STAT` | 打印 armed / active / tick |

占空比单位为千分比：`10 = 1%`，`100 = 10%`，`300 = 30%`。

> 如果串口工具的“字符模式”只可靠发送单个字符，优先使用
> `P` / `F` / `N` / `Q` / `T` / `S` / `E` / `H`。多字符命令必须以 `;`、回车或换行结束。

> ⚠️ `F` 命令绕过 30% 软件限幅，直接输出 100% 占空比 2 秒。
> 只允许在**四轮架空、车体固定**时使用；地面行驶、车轮受阻或 D24A
> 已经偏热时不要发送 `F`。

## 5. 推荐测试顺序

### 5.1 只测 A 路

```text
Z
ENC
A+ 10 800
ENC
A- 10 800
ENC
S
```

判据：

- `A+` 时电机 A 正转；
- `A-` 时电机 A 反转；
- `ENC A` 的计数正负随方向变化；
- 其他 B/C/D 路不应转动；
- D24A 不发热，电流不异常抬升。

### 5.2 B/C/D 逐路重复

每次替换命令首字母：

```text
B+ 10 800
B- 10 800
C+ 10 800
C- 10 800
D+ 10 800
D- 10 800
```

每路都确认“只有目标电机转动”。如果命令 A 却 B 转，说明通道映射或
D24A 侧接线标号错误，先改线，不要继续加占空比。

### 5.3 编码器方向核对

对每路分别执行：

```text
Z
A+ 10 1500
ENC
Z
A- 10 1500
ENC
```

目标：同一路正转和反转的计数符号相反；手转输出轴一圈时，
单相应约为 `364 P/r`，四倍频应约为 `1456 count/r`。

字符模式只支持单字符时，A 路用：

```text
DIP1 = OFF
Q
P
Q
N
Q
S
```

判据：`P` 后的 `ENC A` 相对第一个 `Q` 必须有变化，`N` 后的变化方向相反。

### 5.4 四路逐台单字符测试

串口工具只能稳定发送单字符时，按下面顺序操作：

```text
Q     记录四路初始计数
1     A 正转
Q
2     A 反转
Q
3     B 正转
Q
4     B 反转
Q
5     C 正转
Q
6     C 反转
Q
7     D 正转
Q
8     D 反转
Q
S     停止并解除使能
```

判据：

- 发 `1/3/5/7` 时，只有对应电机正转；
- 发 `2/4/6/8` 时，只有对应电机反转；
- 每一步 `Q` 中，对应编码器计数应变化，其余三路应基本不变；
- 同一路正转与反转的计数增量符号相反。

### 5.5 四路自动轮测

确认四路都能单独动作后，发送单字符：

```text
T
```

固件会依次执行：

```text
A+ → A- → B+ → B- → C+ → C- → D+ → D-
```

每一步为 10% 占空比、800 ms，间隔 300 ms，并打印：

```text
AUTO A+
DONE A+ delta=...
AUTO A-
DONE A- delta=...
...
AUTO TEST DONE
```

判据：

- 每一步只有对应电机转动；
- `delta` 绝对值应明显大于 0，同一路正反转符号相反；
- 任一步异常时立即发 `S` 或 `E`，自动序列会中止；
- 四路 `delta` 数量级应接近；若某一路接近 0，先查该路编码器线序。

### 5.6 首次落地直行

四路单机测试和 `T` 自动轮测通过后，才做行驶测试。

第一次必须先把车架空：

```text
Q
W
Q
S
```

判据：

- 四轮应朝同一物理前进方向转；
- `Q` 中 A/B/C/D 四路计数都应变化，正负号一致；
- 若 C 的物理方向与 A/B/D 相反，回到 C 路方向修正，不要落地；
- 若某一路不动或计数不变，先按单路测试排查。

架空确认后再落地低速直行：

```text
W
```

确认车向前直行且不偏转，再发：

```text
S
```

当前 `W/X` 为 20% 占空比，是首次行驶的安全值。确认直行方向、线性和 D24A
温升都正常后，再提高占空比或加入横移、自转和速度闭环。

### 5.7 K1 直线 + 原地转向路径

`K1` 是 M 板右下角用户按键，对应 STM32 **PD8**，按下为低电平。
固件在 1 kHz 控制任务中做 30 ms 消抖；按下一次触发一轮：

```text
前进 20 cm
  → 原地左转
  → 后退 20 cm
  → 原地右转
```

每段使用 20% 占空比，四轮编码器平均绝对计数达到阈值后切换下一段。
距离换算：

```text
轮径 60 mm，周长 188.50 mm
编码器 1456 count/圈
0.1295 mm/count
200 mm ≈ 1545 count/轮
```

每段最长 4 秒。若编码器失效或轮子打滑导致 4 秒仍未达到阈值，本轮
自动中止并停车，串口打印：

```text
K1 SQUARE ABORT: leg timeout
```

串口过程信息：

```text
K1 PATH START: FWD TURN_L BWD TURN_R
K1 LEG FWD
K1 LEG TURN_L
K1 LEG BWD
K1 LEG TURN_R
K1 SQUARE DONE
```

首次验证顺序：

1. 四轮架空，按一次 `K1`，确认四段轮速组合正确；
2. `FWD/BWD` 时四轮同向反向；
3. `TURN_L/TURN_R` 时左右轮组反向；
4. 落地在空旷区域按 `K1`，观察前进后退与转向；
5. 实际不足 20 cm 则调大 `SQUARE_TARGET_COUNTS`，超出则调小；
6. 任何时候发 `S`、`E` 或再按 `K1` 前先停车，均会中止方阵。

### 5.8 K2 原地左转 1 秒

`K2` 是 M 板第二个用户按键，对应 STM32 **PD9**，按下为低电平，同样有
30 ms 消抖。

按下一次 `K2` 后，四轮按原地左转（逆时针）组合运行：

```text
A- B- C+ D+
```

运行时长为 **1000 ms**，占空比 20%。到时固件自动停车并拉低 `STBY`。

串口过程信息：

```text
TURN LEFT duty=200 ms=1000
TURN LEFT DONE
```

判据：

- 按下 K2 后车应原地左转，车体中心基本不位移；
- 四轮应同时起转、同时停；
- 1 秒结束后必须自动停，不需要再发 `S`；
- 若实际转向为右转，将左转组合四个符号整体取反；
- 原地转向依赖纵向抓地力，比横移可靠；若打滑，先检查四轮共面。

`K1` 方阵运行期间按 `K2` 不会叠加动作；`K2` 运行期间按 `K1` 也会先停止
当前转向，再启动方阵。任何时刻发 `S` 或 `E` 都会立即停车。

### 5.9 K3 已禁用

`K3` 是 M 板第三个用户按键，对应 STM32 **PD10**，按下为低电平。

**横向平移方案已放弃。** 实测中麦轮横移反复打滑，即便正确轮位组合也无法稳定平移，
因此固件已移除所有横移入口：

- `K3` 不再触发任何动作；
- 串口 `L` 命令已移除；
- `K1` 路径中的横向段已替换为原地转向。

底盘只保留三种运动：前进/后退直行、原地左转、原地右转。
这三种都只依赖纵向摩擦力，不依赖麦轮辊子的侧向抓地力。

### 5.4 四路短时同步

只有单路全部通过后，才做四路短时低占空比测试：

```text
ARM
RUN A + 10 800
RUN B + 10 800
RUN C + 10 800
RUN D + 10 800
S
```

这条命令序列只逐路启动，不会同时启动四路；用于确认连续操作不会触发
电源跌落或 D24A 异常。

### 5.5 STBY 软急停

运行任一路时发送：

```text
E
ENC
STAT
```

判据：

- 电机立即断电滑行；
- `STBY` 回低；
- `STAT` 显示 `armed=0`；
- 发送 `ARM` 后仍不能自动恢复转动，必须重新发运动命令。

## 6. 无串口时的 Watch 测试

若 PWLINK2 串口暂时不可用，可在 Keil 调试会话的 Watch 窗口观察并修改变量：

```text
g_armed
g_test_trigger
g_test_motor      0=A 1=B 2=C 3=D
g_test_dir        1=正转 -1=反转
g_test_duty_permille
g_test_duration_ms
```

操作顺序：

1. 设置 `g_armed = 1`；
2. 填好 `g_test_motor / g_test_dir / g_test_duty_permille / g_test_duration_ms`；
3. 设置 `g_test_trigger = 1`；
4. 观察电机和 `ENC`；
5. 若需要立即停止，设置 `g_armed = 0`，或写 `g_estop_request = 1`。

## 8. 常见故障

| 现象 | 优先检查 |
|---|---|
| 四路都不转 | `STBY` 是否为高；D24A 是否有 VM；是否已 `ARM` |
| 发 A 命令但错路转 | A-D 电机线和编码器线是否一一对应 |
| 电机转但编码器不变 | 编码器 VCC/GND 线序；E1A/E1B 是否接对 |
| 编码器计数方向反 | A/B 相是否接反；软件方向符号是否统一 |
| 一上电就转 | `STBY` 是否被跳线帽硬拉高；方向线是否被外部上拉 |
| 串口无回显 | `PC4/PC5` 是否交叉；PWLINK2 串口驱动是否为正常 COM |
| 电池电压明显不对 | D24A `ADC` 是否接 PA4；1/11 分压口径是否一致 |
