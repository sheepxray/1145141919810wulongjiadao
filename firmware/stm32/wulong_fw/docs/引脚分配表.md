## 电机 / 编码器实际座序（2026-10-17 逐轮目视复核）

> ⚠️ **2026-10-16 那一版记错了。** 当时靠"编码器符号翻转"推断 C、D 插座互换，
> 于是固件把两路整体对调；2026-10-17 用逐轮点动、目视哪一个角在转的方法直接
> 复核，证明**插座本来就是一一对应的**——那次对调是过度补偿，已撤销。

| 逻辑轮位 | D24A 座 | PWM | 方向脚 | 编码器 | 极性翻转（`FLIP`） |
|---|---|---|---|---|---|
| A = 左前 FL | A 座 | PA8 / TIM1_CH1 | PB0 / PB1 | TIM2（PA0/PA1） | 0 |
| B = 左后 RL | B 座 | PA9 / TIM1_CH2 | PE4 / PE5 | TIM3（PA6/PA7） | **1**（2026-10-17 实测倒转） |
| C = 右后 RR | C 座 | PA10 / TIM1_CH3 | PB10 / PB11 | TIM4（PB6/PB7） | **1** |
| D = 右前 FR | D 座 | PA11 / TIM1_CH4 | PD2 / PC12 | TIM20（PE2/PE3） | 0 |

> **`FLIP <0-3> [0|1]` 是"整轮翻转"**：它同时**反转该轮的方向线**并**翻转该轮编码器
> 符号**——这正是"电机装反了"所需要的。只改其中之一会让编码器仍然读正、轮子却倒着
> 转，**逐路符号测试查不出来**（B 和 D 都栽在这上面）。默认值在
> `wulong_control.c` 的 `s_flip[]`。

> **验证方法**（判断轮位只能靠这个，符号自洽不能替代）：
> ```text
> S ; Z
> A+ 300 1500   停 2s   <- 应只有左前轮转
> B+ 300 1500   停 2s   <- 左后
> C+ 300 1500   停 2s   <- 右后
> D+ 300 1500   停 2s   <- 右前
> S
> ```
> 对不上就改上表，然后**四处同步**改代码。

> 代码位置：`Core/Src/wulong_control.c` 的 `Wulong_SetWheelDuty()` /
> `Wulong_GetEncoder()`，以及 `Core/Src/main.c` 的 `MotorTest_SetOutput()` /
> `MotorTest_ReadEncoder()`。四处都按上表映射，改一处必须同步改另外三处。
>
> **四路的极性都可以运行时切换**：`FLIP <0-3>` 现场翻转，
> **哪种设置能让车直线行驶，哪种就是对的**。改完记得把结论写回 `s_flip[]` 默认值，
> 别只留在运行态。

## K230D 对接（立创庐山派 Lite-K230D）

### 40Pin 排针（Lite-K230D 已验证）

| 物理脚 | 信号 | 接到 |
|---|---|---|
| Pin 37 | GPIO32 / UART3_TXD | PA3（STM32 RX） |
| Pin 40 | GPIO33 / UART3_RXD | PA2（STM32 TX） |
| Pin 39 | GND | GND（共地） |
| Pin 2 / 4 / 17 | 5V0 / 3V3 | 不接 |

### GH1.25-4P 座（另一种引出）

座子线序（官方）：`5V / RXD / TXD / GND`

| 座子脚 | 信号 | 接到 |
|---|---|---|
| 1 | 5V | 不接 |
| 2 | RXD | PA2（STM32 TX） |
| 3 | TXD | PA3（STM32 RX） |
| 4 | GND | GND（共地） |

40Pin 排针默认使用 UART3 = GPIO32(TXD) / GPIO33(RXD)，已完成 30 帧实机
接收验证；UART2 备选为 GPIO05(TXD) / GPIO06(RXD)。GH1.25-4P 座使用
UART2 = GPIO11(TXD) / GPIO12(RXD)。**UART0 被系统占用，不可用。**

## 已解决的冲突

| 原问题 | 处理 |
|---|---|
| PB3 同时分给 IMU INT 和拨码 | 拨码占 PB3（DIP4），**IMU INT 改到 PB9** |
| BIN1/BIN2 原写 PC4/PC5 | 改 **PE4/PE5**（PC4/PC5 让位调试串口） |
| 编码器 D 曾「待定」 | 定 **TIM20 = PE2/PE3**，硬件正交解码 |
| 调试串口原写 PA14/PA15 | 改 **PC4/PC5**（PA14 是 SWCLK，占用会废掉 SWD） |
| 电池 ADC 原写 ADC1_IN4 | 实为 **ADC2_IN17** |
| 一度以为 C、D 电机插座与轮位互换（2026-10-16 据编码器符号推断） | ❌ **推断有误，已撤销**。2026-10-17 用逐轮点动目视复核，证明插座与轮位本来就一一对应。教训：**轮位只能目视确认，编码器符号自洽不能替代**（方向线取反会同时翻转极性，两种设置都自洽） |
