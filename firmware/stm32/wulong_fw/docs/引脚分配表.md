## K230D 对接（立创庐山派 Lite-K230D）

GH1.25-4P 座子线序（官方）：`5V / RXD / TXD / GND`

| 座子脚 | 信号 | 接到 |
|---|---|---|
| 1 | 5V | 不接 |
| 2 | RXD | PA2（STM32 TX） |
| 3 | TXD | PA3（STM32 RX） |
| 4 | GND | GND（共地） |

K230D 侧 UART2 = GPIO11(TXD) / GPIO12(RXD)。**UART0 被系统占用，不可用。**

## 已解决的冲突

| 原问题 | 处理 |
|---|---|
| PB3 同时分给 IMU INT 和拨码 | 拨码占 PB3（DIP4），**IMU INT 改到 PB9** |
| BIN1/BIN2 原写 PC4/PC5 | 改 **PE4/PE5**（PC4/PC5 让位调试串口） |
| 编码器 D 曾「待定」 | 定 **TIM20 = PE2/PE3**，硬件正交解码 |
| 调试串口原写 PA14/PA15 | 改 **PC4/PC5**（PA14 是 SWCLK，占用会废掉 SWD） |
| 电池 ADC 原写 ADC1_IN4 | 实为 **ADC2_IN17** |
